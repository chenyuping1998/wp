# Saucer Monkey（飛碟農場）— 動畫需求單

2026-10-16。美術見 `SAUCER_美術需求單.md`，音效見 `SAUCER_音效需求單.md`。
本單列出**每一個會動的東西**：誰動、什麼時候動、怎麼動、多久，以及要改哪支程式。

> 給執行者（Codex）：本款從 `StrikeMonkey保齡球館` 複製，**所有演出元件都已經存在**，現在播的是保齡球的版本
> （球滾過畫面的轉場、背景的球道計分螢幕、球瓶粒子……）。本單是把它們逐項改成飛碟版本，**不是從零做**。
> 時間數字是目標值，可以 ±15% 調整到好看為止；Turbo 時程式會自動縮短，不用另外做。
> 客製動作只寫在本 app，**不要改 `wp/packages`**。

---

## 0. 原則

1. **牽引光柱是全款的動作母題**：收集、升級、轉場都用「光柱打下來 → 東西飄起來 → 被吸走」的節奏。光柱一律由下往上吸，不要做成往下砸。
2. **重量感**：乳牛是重的——飄起來前要先「蹲」（壓扁 8%），起飛慢、加速快；飛碟是輕的——懸停時上下浮動 4–6px、週期 1.6s。
3. **好笑在停頓**：每個大動作之前留 80–150ms 的「愣住」（角色瞪眼、乳牛轉頭看鏡頭），之後才發生。
4. **網格（mesh）與 Spine 分工**：符號、背景道具、FG 面板裝飾、大獎牌匾裝飾都是 **mesh**（`src/game/meshWin/`）；兩隻猴子是 **Spine**。
   讀取頁三格說明**不做網格**（使用者規則：會被切割）。
5. 不做呼吸光暈、不做全畫面白閃（送審與使用者都退過）。

## 1. 角色（Spine）

骨架、9 個動作的名稱不變；**動作內容寫在 `design/theme_cast_motions.mjs`**（現在是 Strike 的投球動作），改寫成下表後跑 `node design/generate_monkey_spine.mjs`。
飄動部位寫在 `design/cast_cut/*_rig.json` 的 `flow`（用 `design/add_flows.py` 依顏色擷取），幅度掃到 `check_cast_flow` 允許的上限。

### MG 艦長猴

| 動作 | 觸發 | 長度 | 內容 |
|---|---|---|---|
| `idle` | 待機循環 | 4.8s | 一手叉腰、一手拿遙控器輕敲掌心；重心左右換腳；每 2 輪看一次天空（頭仰 8°） |
| `nod` | 小獎 | 0.8s | 對盤面比一個「OK」手勢，下巴一抬 |
| `cheer` | 中獎 | 1.7s | **按遙控器**：蹲低 → 手臂高舉遙控器 → 大拇指用力按下（停 120ms）→ 身體後仰被反作用力推一下 |
| `chestbeat` | BIG 以上 | 依大獎節拍 | 雙手輪流朝天比「發射」手勢，跟著 10 個重音左右換手；披肩大幅擺動 |
| `throwit` | 進 FG 前 | 1.0s | 把遙控器往上拋、轉一圈接住（道具：遙控器圖，256×256），然後指向畫面中央 |
| `flinch` | 期待落空 | 0.6s | 頭盔天線被電到一樣抖一下，眼睛變大 |
| `alert` | 期待開始 | 0.8s | 敲兩下頭盔、天線豎直 |
| `glance` | 隨機待機 | 1.2s | 偷看左邊的盤面，再若無其事轉回來 |
| `flutter` | 收集中 | 循環 | 單手舉遙控器、身體隨光柱節奏輕晃 |

- **大笑**（`laugh_*` 表情四張）接在 `chestbeat` 的 peak，照 `design/laugh_motion_v9.mjs` 的時序。
- 頭盔（透明玻璃層）**跟頭骨走**，不要自己飄；天線用 flow（彈簧感：先延遲、後過衝 2 次）。
- 披肩 flow：idle 時小幅、`cheer`／`chestbeat` 時大幅。

### FG 農場小猴

| 動作 | 觸發 | 長度 | 內容 |
|---|---|---|---|
| `idle` | 待機循環 | 6s | 手電筒照來照去（手臂慢慢掃 ±14°），偶爾抬頭看天 |
| `nod` | 小獎 | 0.9s | 用力點頭兩下，鍋子跟著跳 |
| `cheer` | 計量表升級 | 1.6s | **照麥田圈**：兩手握手電筒往下照、腳尖踮起、驚喜張嘴 |
| `chestbeat` | FG 大獎 | 依節拍 | 原地小跳＋揮捕蟲網 |
| `throwit` | FG 開場 | 1.0s | 把小乳牛玩偶往上拋（道具 256×256）|
| `flinch` | 期待落空 | 0.6s | 鍋子滑下來蓋住眼睛，再推回去 |
| `alert`／`glance`／`flutter` | 同 MG | | 手電筒跟著視線方向 |

- 捕蟲網的網袋、襯衫下擺、尾巴都是 flow。
- 鍋子**跟頭骨走**，嚇到時（`shock` 表情）往上跳 18px 再落回。

## 2. 符號網格（落地、待機、中獎）

程式位置：`src/game/meshWin/`。現行骨架是 `strikeWins.ts`（獎盃、球鞋…的座標），**換圖後新寫一支 `saucerWins.ts`**，
依新圖量出本體與配件的位置，`acts.ts`、`index.ts` 改 import 它。落地／待機／收集的動作由 `acts.ts` 依配件自動產生，只要配件定對就有。
換完符號圖要先跑 `python design/make_jade_mesh_layers.py`（陰影與低分字層），再跑 `node design/check_mesh_wins.mjs`。

| 符號 | 配件（會動的那一塊） | 落地（0.35s） | 待機小動作（盤面靜止時隨機） | 中獎循環（1.2s） |
|---|---|---|---|---|
| H1 雷射槍 | 槍口的同心圓波紋 | 壓扁回彈，波紋晚 60ms 抖一下 | 槍口冒一圈波紋（往外擴、淡出） | 後座力：整支往後一頓 → 波紋連發三圈 |
| H2 太空頭盔 | 彈簧天線＋頂球 | 天線彈兩下 | 天線慢慢晃一圈 | 頭盔左右搖、天線大幅甩動，頂球閃紅 |
| H3 錫箔帽 | 頂上小球 | 錫箔「皺」一下（橫向壓 6%） | 頂球轉一圈 | 帽子跳起 20px 轉半圈落回 |
| H4 月球汽水 | 吸管＋泡泡 | 汽水晃一下 | 泡泡往上冒 2–3 顆 | 瓶身左右搖、泡泡湧出 |
| W 艦長圖章 | 頭盔天線 | 圓框砸下 + 天線彈 | 艦長眨眼（換一格）或挑眉 | 圓框放大 8% 脈動、天線甩 |
| S 金飛碟 | 透明頂罩 | 碟身斜 15° 落下後擺正 | 底燈逐顆亮一圈 | 原地懸浮旋轉、外圈放射光轉動 |
| P 乳牛 | 尾巴（＋項圈牌不動，倍數字在上面） | 「咚」落下、蹄子壓扁 | 尾巴甩、偶爾轉頭看鏡頭 | 見第 3 節（被吸走） |
| L 低分牌 | 字（程式字） | 輕彈 | 不做 | 字發綠光一下 |

- **配件與本體之間不能有縫**；拉開時露底就是切圖問題，回美術修。
- 乳牛 P 身上的倍數字**不能跟著尾巴動**，倍數字綁在本體。

## 3. 收集演出（本款的招牌，要做最好玩）

觸發：盤面停下後，有至少 1 個 W 艦長、至少 1 個 P 乳牛（`bookEventHandlerMap.ts` 的 collect 事件，元件 `BanditCollect.svelte`、`SackBadge.svelte`）。
Strike 現在是「球瓶跳起、飛向球王」，改成下面的時間軸（每個 W 依序執行一次；多個 W 時第 2 個起縮短 30%）：

| 時間 | 誰 | 做什麼 |
|---|---|---|
| 0 | W 格 | 圓框放大 1.12、天線豎直；MG 艦長 `cheer`（按遙控器） |
| 0.15s | W 格上方 | **光柱打開**：`sushiFx/tractor_beam.png` 從 W 格往上延伸到盤面頂，寬度從 0 張到格寬 0.9（0.2s），光柱內網點往上流動（UV 位移，循環） |
| 0.35s | 每個 P | 依「離 W 由近到遠」排序，每隻間隔 90ms：先蹲（壓扁 8%，80ms）→ 轉頭看鏡頭（停 100ms）→ 四腳離地往上飄、慢慢自轉 |
| — | 每個 P | 沿弧線飛向 W 格上方的光柱，**被光柱吸進去時縮小到 0.3、往上消失**；倍數字跟著飛（`collect_bananas.png` 小乳牛當拖尾粒子） |
| 每隻到達 | W 格 | 圓框跳一下，W 上方的累計數字 +值（現有 `plate` 數字）；音效 `coin_in`（程式每隻加高 7% 音高） |
| 全部到達 + 0.2s | W 格 | 光柱收回（0.25s，由下往上收）；擬聲字「MOO!」彈出（`ComicPop`，見第 4 節） |
| 結束 | 盤面 | 被收走的 P 格**留原圖**（數學上 P 還在盤面），只是淡回 100%；若下一轉才清盤就照現狀 |

- 乳牛飛的弧線要**往上**（先上再橫），不要像 Strike 的球瓶往 W 平飛。
- 10 隻以上時間隔縮到 50ms，總長不超過 2.4s。
- 光柱素材若來不及，可先用程式畫的綠色漸層矩形＋網點遮罩代替，但最終要換成美術圖。

## 4. 免費遊戲（觸發、轉場、升級）

### 4-1 觸發（3／4／5 個金飛碟）

- 每顆 S 落地依序亮（`scatter_1`～`5`）；第 3 顆起其他 S 開始懸浮旋轉。
- 觸發瞬間：所有 S 往上飄 30px、放射光加大；MG 艦長 `alert`；擬聲字「INCOMING!」。

### 4-2 轉場（`TransitionAnimation.svelte`）

現在是**巨大保齡球從左滾進、停在中間蓋住畫面、再往右滾出**（`smTransitionWipe` + 旋轉）。改成：

| 階段 | 時長 | 內容 |
|---|---|---|
| 進場 | 0.9s | 巨大飛碟（`transition_wipe.png`）從左上方斜斜飛入，**不旋轉**，改成碟身左右擺 ±6°、上下浮動 |
| 停住（遮住畫面） | 0.38s | 飛碟停在正中、底部打出一道全螢幕綠光（光從中心往外擴），這時程式切換 MG→FG 背景（`oncover`） |
| 離場 | 0.85s | 飛碟往右上方加速飛走，留下 3 道速度線 |

- 程式改法：把 `rotation` 改成擺動角度、`ballX` 的路徑改成斜線（加 y），`soundBowlingRoll`／`soundBowlingPins` 換成 `soundSaucerFly`／`soundSaucerBeam`（音效見音效單）。
- 進 FG 前 MG 艦長 `throwit` 丟出的道具（現在是球瓶 `gbP`）改成遙控器。

### 4-3 FG 開場面板

- `fg_intro`（底板）＋`fg_intro_decor`（裝飾）：底板從上方降下（像被飛碟放下來，0.6s 減速）；裝飾層的小飛碟、乳牛各自用 `design/make_decor_meshes.py` 切成 mesh，落地時晃一下、之後慢慢浮動。
- 換裝飾圖後**一定要重跑 `make_decor_meshes.py`**。
- 標題字直接寫在面板上，**沒有標題底板、沒有上方布幕**。

### 4-4 計量表升級（4／8／12 個艦長；`BanditMeter.svelte`）

現在是排瓶猴把「10」推倒換球瓶。改成**麥田圈**：

| 時間 | 內容 |
|---|---|
| 0 | 盤面變暗 30%；FG 農場小猴 `cheer`（手電筒往下照） |
| 0.2s | `chef_cut_in.png`（小猴從玉米田探頭）從畫面下方彈入 |
| 0.5s | 盤面中央出現外星紫的**麥田圈**（程式畫：同心圓線條從中心往外一圈圈畫出來，0.5s） |
| 1.0s | 所有要被替換的低分牌（10，之後 J、Q）同時「被壓平」（垂直壓扁到 0）→ 原地長出乳牛（從 0 彈到 1.1 再回 1.0） |
| 1.4s | 擬聲字「CROP CIRCLE!」；+10 轉的數字從計量表飛到 FS 次數 |
| 1.8s | 麥田圈淡出、盤面恢復亮度 |

### 4-5 FG 結算

- `fg_total`＋`fg_total_decor`：面板從上方降下，裝飾層乳牛群逐隻彈出（間隔 60ms），之後浮動。

## 5. 背景動態（`src/game/meshWin/bgProps.ts`、`Background.svelte`）

現在是 Strike 的兩盞原子吊燈、星芒、植物。全部換成：

| 物件 | 背景 | 動作 |
|---|---|---|
| 風車抽水機 | MG | 葉片慢轉（`spin`，一圈 9s），起風時加速 |
| 天上小飛碟 | MG | 沿橢圓繞小圈（週期 14s），偶爾停下打一道細光柱 1.2s |
| 穀倉門 | MG | 被風吹得晃（`sway` hang，±3°，4s） |
| 遠處乳牛 | MG | 每 15–25s 被細光柱吸起 30px 再放下（乳牛一臉淡定） |
| 星星 | MG／FG | 6–8 顆隨機閃（透明度 0.4↔1） |
| 母艦底燈 | FG | 一圈燈逐顆亮起繞圈（週期 3s） |
| 麥田圈 | FG | 外星紫細線緩慢明暗呼吸（4s）——**這是背景圖的一部分，不是盤面上的演出** |
| 被吸起的乳牛群 | FG | 3–4 頭在光柱裡慢慢自轉上浮再回到原位（循環 8s） |

- 每個物件要有美術交的獨立分件＋座標，t=0 與背景完全貼合；矩形互不重疊。

### 背景螢幕（取代 `BowlingScoreboards.svelte`）

Strike 在 5 個球道螢幕上顯示最近 5 轉的派彩，大獎時閃「STRIKE!」（已暫改成「BEAMED UP!」）。本款改成：

- 只有**一塊**穀倉牆上的雷達螢幕（位置由美術交的座標決定）。
- 內容：綠色掃描線每 2s 掃一圈；最近 5 轉的派彩倍數排成一列點陣字；大獎時螢幕閃「BEAMED UP!」1.6s。
- 新元件命名 `RadarScreen.svelte`，把 `Background.svelte` 裡的 `BowlingScoreboards` 換掉；舊檔可刪。
- 只顯示真實派彩，不虛構資料（Strike 的原則）。

## 2026-10-16 使用者補充與收分實作

使用者明確要求兩款收分各有主題特色，品質以專業動畫師為目標。不可只把獎圖平移到收集者。

飛碟：銀色太空船入場、船底綠色牽引光束開啟、乳牛蓄力起浮、加速向上吸入、船底遮擋消失、抵達後分數跳入、飛碟離場。

入口：`src/components/BanditCollect.svelte`；路徑：`src/game/collectionMotion.ts`。多收集者依序演出，逐顆錯開且總錯開上限480ms。虛擬時鐘不受Turbo影響（收分維持正常速度）；清場會取消等待與動畫。每組來源符號暫暗後復原，事件金額仍由數學book決定。
