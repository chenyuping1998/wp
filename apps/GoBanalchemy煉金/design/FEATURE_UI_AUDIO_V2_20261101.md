# 煉金 特殊機制音效與介面 V2

更新日期：2026-11-01（台北時間）

特殊機制音效加入低鼓、木擊與短殘響，保留原事件長度及角色語音。2400–5800 Hz 寬頻抑制與高頻收斂降低尖銳感；關鍵時刻短暫壓低背景音樂，結束後平順恢復。音量感受仍需用耳機、手機與實際遊戲節奏試聽確認。

UI bar 使用本地原創 SVG 產生的主題面板、按鈕、狀態與徽章。忍者採深色漆器與黃銅，煉金採青綠玻璃與銅。沿用既有投注操作。

Info 頁加入主題標頭、規則／獎表頁籤與可切換的機制示意。保留原規則、RTP、獎金表與法律文字。單次渲染的本地彈窗支援 Escape、Tab 焦點循環、關閉後焦點及捲動還原。窄螢幕與減少動態偏好有對應樣式。
