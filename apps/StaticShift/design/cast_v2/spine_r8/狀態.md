# r8（2026-11-10）：動作修正，圖層不變（交件 r7 / r7.1）

Stone：「動作很奇怪，伸出的手有很不自然的彎曲」。

原因與修法（工具 ~/tools/spine-generator-ss，分支 claude/merge-stand34，未 commit）：
1. gaze 指盤面：solve.ts 的 IK 伸長保護把目標壓在臂長 93–95%，手臂永遠彎 40° 左右，而且手肘朝上凸。
   新增 preset 輸出 `ikLimit`；gaze 的 `reach` > 0.98 時這隻手可以伸到 99.9%（真的打直）。參數 `reach: 1.04`。
2. gaze 出手／收手：手從腰直線走到指向點，中途上臂平舉、前臂垂下（雞翅）。新參數 `swing: 1`：
   手臂先往下打開伸直，再以肩為軸甩上去；收手反著走。
3. 主持人指的手下垂：新參數 `handTilt: 10`（手掌相對前臂轉 10°）。
4. 大獎三段（win_big / loop / end）：遠手整段平舉伸直很僵。新參數 `farHip: 1`：遠手留在腰上。

指令：`node ~/tools/spine-generator-ss/bin/spine-motion.js character 交件/<角色>/layers -o spine_r8/<角色>_L --name <角色> --joints spine_r8/<角色>.joints.layout.json --params spine_r8/<角色>.motion.params.json`
（加 `--frames` 會留下 frames.json、不做 GIF，可用來自己排逐格圖。）
