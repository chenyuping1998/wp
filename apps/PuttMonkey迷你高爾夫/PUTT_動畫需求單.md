# Putt Monkey（迷你高爾夫）— 動畫需求單

2026-10-16。美術見 `PUTT_美術需求單.md`，音效見 `PUTT_音效需求單.md`。
本單列出**每一個會動的東西**：誰動、什麼時候動、怎麼動、多久，以及要改哪支程式。

> 給執行者（Codex）：本款從 `StrikeMonkey保齡球館` 複製，**所有演出元件都已經存在**，現在播的是保齡球的版本。
> 高爾夫跟保齡球很接近（都是「球滾過去」），所以**轉場幾乎可以原樣沿用**，重點在收集演出、升級演出和背景。
> 時間數字是目標值，可以 ±15% 調整到好看為止；Turbo 時程式會自動縮短，不用另外做。
> 客製動作只寫在本 app，**不要改 `wp/packages`**。

---

## 0. 原則

1. **球很調皮**：所有高爾夫球的動作都要有「差一點」的笑點——滾到洞口繞一圈、停在邊緣晃兩下、才掉進去。但**每顆只能有一次**這種停頓，不然收集會拖。
2. **擺動用彈簧感**：風車葉、球旗、毛巾、毛球都是「延遲、過衝、回彈」，不要等速。
3. **好笑在架勢**：高球猴每次推桿前都要擺架勢（瞇眼、舔手指測風、扭屁股），推的時候卻很輕。
4. **網格（mesh）與 Spine 分工**：符號、背景道具、FG 面板裝飾、大獎牌匾裝飾都是 **mesh**（`src/game/meshWin/`）；兩隻猴子是 **Spine**。
   讀取頁三格說明**不做網格**（使用者規則：會被切割）。
5. 不做呼吸光暈、不做全畫面白閃（送審與使用者都退過）。

## 1. 角色（Spine）

骨架、9 個動作的名稱不變；**動作內容寫在 `design/theme_cast_motions.mjs`**（現在是 Strike 的投球動作），改寫成下表後跑 `node design/generate_monkey_spine.mjs`。
飄動部位寫在 `design/cast_cut/*_rig.json` 的 `flow`（用 `design/add_flows.py` 依顏色擷取），幅度掃到 `check_cast_flow` 允許的上限。
推桿是道具圖，綁在 MG 右手骨上（Strike 的 `throwit` 道具綁法可參考）。

### MG 高球猴

| 動作 | 觸發 | 長度 | 內容 |
|---|---|---|---|
| `idle` | 待機循環 | 4.8s | 雙手拄著推桿、重心左右換腳；每 2 輪舔一下手指舉高測風 |
| `nod` | 小獎 | 0.8s | 對盤面舉帽致意（帽子離頭 10px 再放回） |
| `cheer` | 中獎、收集開始 | 1.7s | **推桿**：瞇眼瞄準（頭歪 6°，停 200ms）→ 扭兩下屁股 → 推桿輕輕往前一推 → 定格看球，身體跟著球的方向傾 |
| `chestbeat` | BIG 以上 | 依大獎節拍 | 推桿高舉過頭、左右揮舞，跟著 10 個重音換手；毛球、毛巾大幅甩動 |
| `throwit` | 進 FG 前 | 1.0s | 把推桿往上拋、轉兩圈接住，然後指向畫面中央 |
| `flinch` | 期待落空 | 0.6s | 抱頭、帽子滑歪 |
| `alert` | 期待開始 | 0.8s | 蹲低、手搭眉毛看遠方 |
| `glance` | 隨機待機 | 1.2s | 偷看盤面、用推桿在地上比一下距離 |
| `flutter` | 收集中 | 循環 | 身體跟著滾動的球左右「用意念推」（往球的方向傾） |

- **大笑**（`laugh_*` 表情四張）接在 `chestbeat` 的 peak，照 `design/laugh_motion_v9.mjs` 的時序。
- 帽頂毛球、擦球毛巾、尾巴用 flow；毛球的彈簧感最重（過衝 2 次）。

### FG 球童猴

| 動作 | 觸發 | 長度 | 內容 |
|---|---|---|---|
| `idle` | 待機循環 | 6s | 背著大球袋左右晃、偶爾把球袋往上顛一下（球桿喀啦） |
| `nod` | 小獎 | 0.9s | 豎大拇指，遮陽帽帽沿彈一下 |
| `cheer` | 計量表升級 | 1.6s | **指向火山**：跳起來、單手直指上方、另一手按住帽子 |
| `chestbeat` | FG 大獎 | 依節拍 | 原地小跳，從球袋裡抽出兩支球桿交叉揮 |
| `throwit` | FG 開場 | 1.0s | 把小球旗往上拋（道具 256×256） |
| `flinch` | 期待落空 | 0.6s | 球袋往後倒、整隻被拖得踉蹌 |
| `alert`／`glance`／`flutter` | 同 MG | | |

- 球袋是獨立一層，**跟軀幹走**，`idle`／`chestbeat` 時有一點延遲（重物感）；袋上的毛巾是 flow。

## 2. 符號網格（落地、待機、中獎）

程式位置：`src/game/meshWin/`。現行骨架是 `strikeWins.ts`（獎盃、球鞋…的座標），**換圖後新寫一支 `puttWins.ts`**，
依新圖量出本體與配件的位置，`acts.ts`、`index.ts` 改 import 它。落地／待機／收集的動作由 `acts.ts` 依配件自動產生，只要配件定對就有。
換完符號圖要先跑 `python design/make_jade_mesh_layers.py`（陰影與低分字層），再跑 `node design/check_mesh_wins.mjs`。

| 符號 | 配件（會動的那一塊） | 落地（0.35s） | 待機小動作（盤面靜止時隨機） | 中獎循環（1.2s） |
|---|---|---|---|---|
| H1 風車 | 四片葉（繞中心轉） | 壓扁回彈，葉片被震得轉 1/8 圈 | 葉片慢轉一圈 | 葉片快轉 2 圈後減速、屋身左右晃 |
| H2 恐龍 | 下顎（以顎關節為軸開合） | 下顎「喀」一下 | 打個呵欠（下顎慢開慢合） | 大嘴開合三下（像在吃球） |
| H3 球袋 | 垂下的毛巾＋球桿頭 | 球桿頭喀啦晃 | 毛巾飄一下 | 球袋跳起、球桿頭互撞 |
| H4 檸檬水 | 吸管＋冰塊 | 液面晃 | 吸管轉半圈 | 杯子左右搖、冰塊叮噹 |
| W 高球猴圖章 | 帽頂毛球 | 圓框砸下＋毛球彈 | 瞇眼（換一格）或挑眉 | 圓框放大 8% 脈動、毛球甩 |
| S 金球旗 | 旗面（以旗桿為軸飄） | 旗桿插下、旗面抖 | 旗面隨風飄 | 旗面大幅飄、洞口光環轉 |
| P 高爾夫球 | 旗紅條紋（讓球看起來在轉） | 「咚」彈一下（彈 2 次，第 2 次很小） | 原地輕輕晃，像被風吹 | 見第 3 節（被收走） |
| L 號碼旗牌 | 字（程式字） | 輕彈 | 不做 | 字發天空藍光一下 |

- **配件與本體之間不能有縫**；風車葉、恐龍下顎拆開後露底就是美術沒補畫，回美術修。
- 高爾夫球 P 上的倍數字**不能跟著條紋轉**，倍數字綁在本體。

## 3. 收集演出（本款的招牌，要做最好玩）

觸發：盤面停下後，有至少 1 個 W 高球猴、至少 1 個 P 高爾夫球（`bookEventHandlerMap.ts` 的 collect 事件，元件 `BanditCollect.svelte`、`SackBadge.svelte`）。
Strike 現在是「球瓶跳起、飛向球王」，改成下面的時間軸（每個 W 依序執行一次；多個 W 時第 2 個起縮短 30%）：

| 時間 | 誰 | 做什麼 |
|---|---|---|
| 0 | W 格 | 圓框放大 1.12；MG 高球猴 `cheer`（瞄準、推桿） |
| 0.25s | W 格下緣 | **球洞出現**：`sushiFx/golf_hole.png` 從 0 張開到格寬 0.6（0.15s），一支小球旗從洞裡彈出來插好 |
| 0.4s | 每個 P | 依「離 W 由近到遠」排序，每顆間隔 90ms：先彈一下（離地 12px）→ **沿著平滑曲線在格子上方「滾」向 W**（條紋配件轉動、軌跡略帶 S 形，不要直線） |
| — | 每個 P | 到洞口時：**一半的球直接掉進去**，**另一半繞洞口轉半圈再掉進去**（隨機，但同一顆球每次播放結果一致，用格子座標當種子）；掉進去＝縮小到 0.4 往下沉、消失 |
| 每顆進洞 | W 格 | 小球旗抖一下、W 上方的累計數字 +值（現有 `plate` 數字）；音效 `coin_in`（程式每顆加高 7% 音高） |
| 全部進洞 + 0.2s | W 格 | 球洞收合（0.2s）；擬聲字「SINK IT!」或「PLOP!」彈出（`ComicPop`，見第 6 節） |
| 結束 | 盤面 | 被收走的 P 格**留原圖**（數學上 P 還在盤面），淡回 100% |

- 繞洞口的那半圈最多 180ms，10 顆以上時**取消繞圈**、間隔縮到 50ms，總長不超過 2.4s。
- 滾動的拖尾粒子用 `collect_bananas.png`（小高爾夫球）＋草屑。

## 4. 免費遊戲（觸發、轉場、升級）

### 4-1 觸發（3／4／5 個金球旗）

- 每支 S 落地依序亮（`scatter_1`～`5`）；第 3 支起其他 S 的旗面開始大幅飄。
- 觸發瞬間：所有 S 的旗桿往上拔高 20px 再插回、洞口光環擴散；MG 高球猴 `alert`；擬聲字「TEE TIME!」。

### 4-2 轉場（`TransitionAnimation.svelte`）

現在是**巨大保齡球從左滾進、停在中間蓋住畫面、再往右滾出**。高爾夫版**沿用同一套路徑與旋轉**，只換：

| 階段 | 時長 | 內容 |
|---|---|---|
| 進場 | 0.9s | 巨大高爾夫球（`transition_wipe.png`）從左滾入（旋轉照舊） |
| 停住（遮住畫面） | 0.38s | 停在中間時**在原地晃兩下**（像在洞口邊緣猶豫，左右 ±4°），這時程式切換 MG→FG 背景（`oncover`） |
| 離場 | 0.85s | 往右滾出 |

- 音效 cue 已改名：球滾動 `soundGolfRoll`（`golf_roll.wav`）、停住時 `soundGolfCup`（`golf_cup.wav`，球掉進洞的「咕咚」＋觀眾「喔～」）。
- 進 FG 前 MG 高球猴 `throwit` 丟出的道具（現在是球瓶 `gbP`）改成推桿。

### 4-3 FG 開場面板

- `fg_intro`（底板）＋`fg_intro_decor`（裝飾）：底板從下方彈上來（像記分板被立起來，0.6s 帶過衝）；裝飾層的球、球旗、小火山各自用 `design/make_decor_meshes.py` 切成 mesh，落地時晃一下、之後球旗慢慢飄。
- 換裝飾圖後**一定要重跑 `make_decor_meshes.py`**。
- 標題字直接寫在面板上，**沒有標題底板、沒有上方布幕**。

### 4-4 計量表升級（4／8／12 個高球猴；`BanditMeter.svelte`）

現在是排瓶猴把「10」推倒換球瓶。改成**火山噴發**：

| 時間 | 內容 |
|---|---|
| 0 | 盤面變暗 20%；FG 球童猴 `cheer`（指向火山） |
| 0.2s | `chef_cut_in.png`（球童猴探頭）從畫面下方彈入 |
| 0.4s | **背景的火山噴發**（bgProps 的火山 mesh 做一次「噴」：山口膨脹 1.15 → 噴出熔岩橘粒子），畫面輕震 3px |
| 0.7s | 每個要被替換的低分牌（10，之後 J、Q）上方落下一顆熔岩球（熔岩橘、帶煙尾，程式畫或粒子圖），間隔 40ms |
| 落下時 | 低分牌被砸扁（垂直壓到 0.2）→ 冒一團白煙 → 煙散開時原地是一顆高爾夫球（從 0.6 彈到 1.1 再回 1.0） |
| 1.5s | 擬聲字「KABOOM!」；+10 轉的數字從計量表飛到 FS 次數 |
| 1.9s | 盤面恢復亮度 |

### 4-5 FG 結算

- `fg_total`＋`fg_total_decor`：記分板彈上來，裝飾層的高爾夫球一顆顆從上方掉進畫面、堆起來（間隔 60ms）。

## 5. 背景動態（`src/game/meshWin/bgProps.ts`、`Background.svelte`）

現在是 Strike 的兩盞原子吊燈、星芒、植物。全部換成：

| 物件 | 背景 | 動作 |
|---|---|---|
| 風車洞的風車 | MG／FG | 葉片慢轉（`spin`，一圈 8s） |
| 恐龍洞的恐龍 | MG | 下顎每 6–10s 開合一次；偶爾吐出一顆球滾走 |
| 火山 | MG | 頂上白煙慢慢冒（煙用 `drape` 往上飄、淡出，循環 5s） |
| 火山 | FG | 熔岩光脈動（3s）、每 10–15s 小噴一次；**4-4 的大噴發也用這個物件** |
| 遮陽傘 | MG | 被風吹得晃（`sway` stand，±3°，4s） |
| 球旗 | MG／FG | 2–3 支遠處球旗的旗面飄 |
| 雲 | MG | 2 朵雲非常慢地往右飄（30s 一趟，出畫面後從左回來） |
| 小燈串 | FG | 球道邊的燈泡逐顆亮起繞圈（週期 3s） |

- 每個物件要有美術交的獨立分件＋座標，t=0 與背景完全貼合；矩形互不重疊。

### 背景記分板（取代 `BowlingScoreboards.svelte`）

Strike 在 5 個球道螢幕上顯示最近 5 轉的派彩，大獎時閃「STRIKE!」（已暫改成「HOLE IN ONE!」）。本款改成：

- **一塊**球場記分板（黑板，位置由美術交的座標決定），上面 5 欄標「HOLE 1」～「HOLE 5」，每欄寫該轉的派彩倍數（粉筆字感：奶油色、略抖）。
- 新的一轉寫在最右欄，舊的往左推；大獎時該欄畫一個粉筆圈＋閃「HOLE IN ONE!」1.6s。
- 新元件命名 `CourseScoreboard.svelte`，把 `Background.svelte` 裡的 `BowlingScoreboards` 換掉；舊檔可刪。邏輯（最近 5 轉、只顯示真實派彩）照搬 Strike。

## 2026-10-16 使用者補充與收分實作

使用者明確要求兩款收分各有主題特色，品質以專業動畫師為目標。不可只把獎圖平移到收集者。

高爾夫：球洞與旗入場、推桿起動、球體沿曲線滾動並隨透視縮小、洞緣繞行、短暫停頓、下沉入洞、抵達後分數跳入。球體旋轉時數字保持正向。

入口：`src/components/BanditCollect.svelte`；路徑：`src/game/collectionMotion.ts`。多收集者依序演出，逐顆錯開且總錯開上限480ms。虛擬時鐘不受Turbo影響（收分維持正常速度）；清場會取消等待與動畫。每組來源符號暫暗後復原，事件金額仍由數學book決定。
