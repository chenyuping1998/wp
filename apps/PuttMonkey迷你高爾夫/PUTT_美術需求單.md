## 2026-10-16 使用者補充：製作品質與低獎圖

- 主風格與獎圖以清楚輪廓、低 AI 感、專業 SLOT 團隊的完成度為目標；此項優先於單純增加紋理、光暈或裝飾。
- 高獎圖先通過黑色剪影與 70px 縮圖辨識，再檢查材質與陰影。統一外輪廓粗細、光向、視角與填色密度；細節不能破壞主形。
- 低獎圖不能只用線條或裸字母。球洞旗牌：有厚度的奶油色旗面、短旗桿、草皮底座，角落放小球與球座。旗桿、球與草皮不能侵入字母主體與字腔。
- 低獎圖仍由程式排 A／K／Q／J／10，文字是第一閱讀層，主題配件是第二閱讀層；保留完整中央留白，不將字母烘進正式底牌。
- 低獎圖的對比與細節密度低於 H1–H4／W／S，避免低獎圖搶過高獎圖。五張需共享同一組結構與比例。
- 最終檢查包含 512px 原圖、70px 單符號與 200px 寬全盤。生成樣張僅供美術方向確認，不能當作已切層、已整合的正式遊戲截圖。

## 0. 畫風方向：1960 年代夏日度假明信片

**路邊的迷你高爾夫球場 × 1960 年代度假明信片／旅遊海報平塗**：大晴天、圓潤的造型、紙張質感、色塊之間微微套色偏移。
球場上有誇張的障礙物——會轉的風車、張大嘴的恐龍、冒煙的火山、彎來彎去的球道。像一張 1962 年「全家一起來打迷你高爾夫！」的明信片。

關鍵字：**圓角、豆形與雲朵形、波浪邊、紙紋、粗顆粒網點（少量）、陽光、遮陽傘、白色木柵欄、人工草皮的條紋、彎曲球道。**

### 跟 Strike 怎麼分（最重要）

| | Strike（保齡球館） | Putt（本款） |
|---|---|---|
| 時間 | 夜晚、室內、霓虹 | **白天、戶外、陽光** |
| 造型 | 尖角、星芒、迴旋鏢 | **圓角、雲朵、波浪** |
| 主色 | 夜青墨＋奶油＋石板青 | **草皮綠＋天空藍＋奶油** |
| 質感 | 霓虹光暈 | **紙紋＋陽光的暖色陰影** |

### 有趣感怎麼做（每張圖都要檢查）

1. **障礙物是活的（但不畫臉）**：風車會轉、恐龍嘴會開合、火山會噴——它們是會「搗蛋」的機關，但**獎圖本身不畫眼睛嘴巴**（恐龍是石膏雕像，眼睛是兩個圓點即可，不要表情）。
2. **高爾夫球很調皮**：球會彈、會繞圈、會卡在洞口晃一下才掉進去——這是收集演出的笑點。
3. **角色要有「打高爾夫的人」的誇張架勢**：瞇眼看線、舔手指測風、推桿前扭屁股。
4. **字（FORE!、PLOP!、HOLE IN ONE!）由程式排**，生圖不畫字。

### 色卡

| 色 | hex | 用途 |
|---|---|---|
| 墨綠黑 | #1B2A22 | 輪廓、深色面板 |
| 奶油 | #FFF6DF／#F4EACB | 底色、面板底、字、高爾夫球本體 |
| 草皮綠 | #3E7A45／#2F5E36／#7FB06A | 球道、中間調、陰影、UI 圓鈕 |
| 旗紅 | #E5432F | **價值色**：H1、W、大獎、按鈕、球旗、高爾夫球的條紋 |
| 鉻金 | #F5B83D | **只給 Scatter 金球旗和大獎光芒** |
| 天空藍 | #3FB4E8 | **機制色**：天空、收集線、計量表、收集中的框（盤面上少量） |
| 熔岩橘 | #F27A1A | **只給 FG 升級**（火山噴發、10／J／Q 變高爾夫球）與 FG 的火山夕陽 |

- 正常畫面約 75% 是奶油、草皮綠、天空藍（天空可以大面積）。旗紅集中在焦點，面積 ≤12%；鉻金在一般盤面 ≤3%。
- 程式端 UI 已換成這組色碼（`src/game/uiTheme.ts` 與各元件），圖要配合它。

### 筆法

- 平塗＋最多一階陰影；陰影偏暖（陽光感），可以用少量粗網點；**不要寫實漸層**。
- 輪廓線粗細一致，約畫布邊長 1.5%，線條圓潤、端點圓頭。
- **不得模仿任何現存角色、品牌或球場**：不畫真實高爾夫品牌、真實球場招牌、知名卡通高爾夫角色；恐龍不要像任何電影的恐龍。
- 不畫提基（tiki）面具、原住民圖騰等文化符號——迷你高爾夫常見，但本款一律不用。

### 禁止事項

- **生圖不畫字**：招牌、記分板、球洞號碼牌、Logo 一律留白，字全部由程式排。
- 不畫啤酒、雞尾酒、抽菸（檸檬水就是檸檬水）。
- 不畫人類，角色只有猴子。
- 透明資產必須是真正的 RGBA；奶油色高爾夫球**不可以用白色去背挖掉**。

### 驗收

- 符號縮到 **70px** 與全盤 **200px 寬**時，4 個高分要靠**剪影**分得出來。
- 跟 Strike、Saucer、Diner、Mardi、Swing 放在一起看，第一眼要能看出是不同遊戲，**特別是跟 Strike 並排時**。
- 每批交件附一張 contact sheet，放在 `design/source/putt/_sheets/`。

## 4. 角色（Spine，`static/assets/spines/sushiMaster/`、`sushiApprentice/`）

沿用現有骨架與 9 個動作：`idle`、`cheer`、`chestbeat`、`nod`、`throwit`、`flinch`、`alert`、`glance`、`flutter`。
**拿 Strike 現有角色的姿勢與骨架比例改造型**，再重新切圖、產生 atlas
（流程見 `design/cut_cast_layers.py`、`design/generate_monkey_spine.mjs`、`design/check_cast_flow.mjs`）。
動作的節奏與道具見 `PUTT_動畫需求單.md` 第 1 節。

| | MG 高球猴（`sushiMaster`） | FG 球童猴（`sushiApprentice`） |
|---|---|---|
| 體型 | 圓肚、短腿、大圓頭 | 瘦小、手腳細長、大眼 |
| 服裝 | 菱格紋毛衣背心（旗紅／奶油）、白襯衫、格紋短褲、高筒襪、雙色高爾夫鞋、報童帽 | 遮陽帽、條紋 polo 衫、卡其短褲、斜背超大球袋 |
| 會飄動的部位（flow） | 帽頂毛球、腰間擦球毛巾、尾巴 | 球袋上垂的毛巾、遮陽帽後的帽帶、尾巴 |
| `throwit` 道具 | 推桿（獨立透明圖 256×256） | 一支小球旗（獨立透明圖 256×256） |

- **推桿要能拿在手上**：MG 的右手層要包含握桿的手，推桿本身另交一張道具圖，程式綁在手骨上。
- **球袋很大**：球袋是 FG 背後的獨立一層，綁在軀幹上；不要讓球袋擋住手臂的活動範圍。
- 站在盤面右側、面向左；全身，雙腳完整。
- 雙手自由下垂、微彎，**前臂和軀幹之間至少留 48px 空隙**（以 1024 寬為準）。
- 原稿 1024×1668 透明 RGBA；可以交整張，也可以交 24 層分件（關節要重疊，被擋住的衣料要補畫）。**切層規則見第 12 節第 4、5 點。**
- 兩隻同光向、同腳底線，頭頂高度差 ≤5%（帽子不算在頭頂高度內）。

**表情**（每隻 8 張頭部，各 512×512 透明）：
`neutral`、`blink`、`grin`、`shock`、`laugh_inhale`、`laugh_rising`、`laugh_peak`、`laugh_settle`（後四張照 `design/source/v9/laugh/` 的流程接上）。
高球猴的招牌表情是「瞇一隻眼瞄準」，放在 `neutral` 或 `grin` 都可以；嚇到時帽子跳起來、毛球彈。

## 12. 前幾款修過的坑（茶樓／Diner／Monkey King／Strike 交件後才發現、重做過的地方，這次一開始就照做）

**符號與網格**

1. **換完符號圖一定要重跑 `python design/make_jade_mesh_layers.py`**。Diner 換圖後忘了跑，中獎陰影一直是茶樓的輪廓。
2. **獎圖要能拆成「本體＋一個會動的配件」**。配件和本體之間不要有細縫或半透明毛邊，網格動畫拉開時才不會露底。
   本款的風車葉、恐龍下顎拆開後，**被擋住的部分要補畫**（風車葉後面的屋身、恐龍下顎後面的喉嚨）。
3. **背景動態分件要附座標，而且在 t=0 必須跟背景上的原位置完全貼合**（網格一開始就得蓋在原圖上，否則會跳一下）。
   附屬在主體上的部件要跟主體交成**同一組**，或標明它跟著誰縮放；Diner 點唱機的霓虹拱分開交，結果打拍時脫位。
   相鄰的兩個動態分件**矩形不要重疊**，重疊的網格會互相凍住。

**角色切層（最花時間的地方）**

4. **要飄動的部位一定獨立成層，不能混進手臂或跨兩層**。Monkey King 的披風、旗子、尾巴被切進手臂層，結果整組不能飄。
   本款要飄的：MG 帽頂毛球、擦球毛巾、尾巴；FG 球袋毛巾、帽帶、尾巴——每一件都是自己的一層。互相接觸的件（例如毛巾掛在腰帶上、毛巾掛在球袋上）要掛在**同一個父層**底下。
5. **被手臂、大腿蓋住的軀幹要完整補畫**，不是橫向拖影。前臂層只有前臂（不帶衣服邊）；軀幹層把被手臂擋住的衣服、腋下都畫完整；腿在衣服下的部分要畫到大腿根。
   交件時附 `_raw.png`（未切的整張）方便重切。可以用 `design/dump_cast_frames.mjs`＋`design/render_cast_frames.py` 離線看笑、推桿時有沒有裂。
   **人物切線與關節點要依本款原圖重新量，不要沿用 Strike 的**（2026-10-10 六款人物全部因此重切過）。

**介面與版面**

6. **H1／H2／S 的背卡用同一張素卡**，不要依價值做不同背卡。
7. **三格說明要是插畫場景、不做網格**，外框只要一條墨線＋一條細色線。最大贏分那格的留白區由程式排 10,000×，**留白裡不要放任何會被做成動畫的東西**。

9. **盤面框照現有檔案的形狀與開口**：生圖很難一次打中這個比例。打不中就交零件（左右邊條、四角、上下橫條），由程式組。
10. **Buy Bonus 鈕的圖不要因為「看起來暗」就調亮**：本款已設好 `buyBonusIdleTint`，原圖照正常亮度畫即可。
