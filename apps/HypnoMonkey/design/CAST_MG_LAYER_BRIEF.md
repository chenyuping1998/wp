# 催眠師猴（MG）— 動作優先的拆層需求單

2026-10-27。照 spine-motion-kit「第 0 步」：先定動作，再定生圖姿勢與拆層。這份同時是
spine-generator 新模板 **stand34（正面 3/4 站姿）** 的交件規格（工具端說明：`~/tools/spine-generator/docs/站姿模板.md`）。

角色造型以 `board_preview_v4_5x6/mg-character-transparent.png` 為準（紅燕尾服、米白背心、
黑領結、黑禮帽紅帽帶、單片圓眼鏡、長尾）。**那張不能直接拆**：它是一整張圖、背後烤了紅黑光暈
（37% 像素半透明）、雙腳交叉、右手已經停在眼鏡上。請依下面的姿勢重畫一張母圖再拆層。

## 0. 動作清單（Stone 2026-10-27 選定）

| 動作 | 內容 | 對圖的要求 |
|---|---|---|
| idle（待機循環） | 呼吸、重心在兩腳間慢慢移、尾巴延遲甩動、頭微歪；偶爾眨眼 | 兩膝微彎、雙腳分開踩地；尾巴分三節畫；要有閉眼頭 |
| idle_fidget（待機小動作） | 用捏眼鏡的手轉一下單片眼鏡、整理領結 | 眼鏡獨立一層；捏鏡手獨立一張 |
| gaze（催眠一瞪，丟倍率） | 預備下沉 → 前手把眼鏡往下拉 → 螺旋眼 → 另一手伸直指向盤面 → 停 → 回位 | 螺旋眼頭；指向手；指向那隻手的上臂、前臂要能完全伸直不穿幫 |
| react_small（小獎） | 輕點帽緣、得意笑 | 帽子獨立一層，頭頂在帽子下要畫完整 |
| gaze_dud（丟空） | 聳肩攤手、皺眉撇嘴 | 張開手掌兩張；不爽表情頭 |
| fg_trigger / win_big（大獎、FG 觸發） | 下蹲蓄力 → 摘帽高舉、遠手張開、仰頭大笑；大獎循環帽子在頭上畫圈；結束時戴回帽子 | 兩手腋下、肩下、胸側畫完；張開手；抓帽緣手；手抓整頂帽子 |

## 1. 母圖姿勢（生圖前一定要先對）

- 畫布 **1024 × 1536**，透明背景；**不要光暈、不要陰影、不要地面**。地面點在 (512, 1456)，兩腳底踩在 y=1456 這條線上。
- 正面 3/4：身體朝畫面左側（盤面方向）轉約 30°，臉也朝畫面左。畫面左＝角色的右側，稱 **L**；畫面右＝角色的左側，稱 **R**。
- 雙腳**不交叉**：兩腳分開約一個腳掌寬，L 腳在前、R 腳在後，兩膝微彎（不要打直）。重心略偏 R 腳，形成肩與髖反向傾斜。
- **R 手（捏鏡手）**：手肘彎約 100°，手停在胸口高度輕捏翻領。不是停在眼鏡上——拉眼鏡是動作，不是靜止姿勢。
- **L 手（插腰手）**：手背貼在 L 側腰，手肘向外。
- 尾巴從燕尾服下襬後面伸出，往畫面右後方繞成 S 形，尾尖不碰身體。
- 帽子端正戴好、稍微壓眉；眼鏡戴在 L 眼（畫面左的眼）。

## 3. 三條鐵律

1. **被擋處畫完**：每一層單獨看都是完整、連續的部件，沒有缺口、沒有別的部件殘影。
2. **關節兩邊重疊、重疊處不描邊**：多畫的部分收在相鄰部件的外緣以內，不能凸出去；關節不要切平。
3. **同一畫布原位**：每張都是 1024×1536，部件留在母圖上的原本位置，不要裁切、不要置中。
