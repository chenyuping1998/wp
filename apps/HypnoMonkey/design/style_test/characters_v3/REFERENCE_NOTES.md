# 減少 AI 感：風格庫研究與改稿 v3

2026-10-27。Stone：「AI 感不要那麼重，參考風格庫」。沿用已選的絹印方向，重設造型與線條，而非只加表面效果。

## 實際查看的來源

- 風格庫 `Toshi Ways Club` 的 `base_late` 盤面與 palette／atlas 紀錄：大面積紙色與灰墨，活躍色有角色分工，圖形留白多。取用「少量主色、空間安靜、墨線先行」的決策，不挪用昭和／VHS 主題。
- 風格庫 `Donut Division` 的 `base_late` 盤面：角色由垂眼皮、窄眼、鬍形與高低肩的姿態表現性格，臉不是一律大眼大笑。取用「眼皮和體態講性格」。
- 風格庫 `Le Bandit` 的 `base_late` 盤面：角色的重心、頭身、短而清楚的手腳輪廓先於裝飾；眉眼的負形比小細節重要。取用「先看剪影與負形」。不複製浣熊、服裝、配色或 rig。

研究接觸表僅在 workspace 的 `research/hypno-screenprint-20261027.jpg`、`research/hypno-character-refs-20261027.jpg`；不打包、不作為 imagegen 輸入。模型只收到我們自有的 V2 角色圖和文字拆解。

## V2 的問題與 V3 的處理

| V2 的問題（本次視覺判斷） | V3 的改動 |
|---|---|
| 均勻粗黑邊像通用向量貼紙 | 有筆壓、轉折和收筆的手繪墨線 |
| 兩人都用圓滑面頰、大眼、大笑嘴 | 男角瘦長垂臉、女角短寬方圓臉；兩種眼皮和嘴角 |
| 角色靠帽子與羽毛辨認，臉形相近 | 去掉裝飾後仍可由顱形／口鼻／下巴區分 |
| 鬍鬚和髮束重複成漂亮圖案 | 不對稱鬍形、頭髮三大形、少量有功能內線 |
| 原始圖的柔陰影壓色後變斑點 | 從源圖要求大塊硬邊暗面，不靠量化補救造型 |
