# 暖灰盤底版本

依 Stone 指出藍盤底會降低部分藍色圖騰辨識度，盤格與獨立圖鑑的底色改為低彩度暖灰 `#B8B1A4`。十種圖騰、角色、背景和排法沿用上一版。

- `HypnoMonkey-full-board.png`：1920×1440 完整盤面示意。
- `HypnoMonkey-all-symbols.jpg`：暖灰底的十種圖騰圖鑑。
- `readability-70px.jpg`：藍底／暖灰底在 70px 下的同素材比較。
- `manifest.json`：盤底色、來源目錄、來源 hash、盤格配置。

重建：`python3 design/build_full_board_preview.py`。

來源仍保存在 `../board_preview_v1/source/`；新版本未重畫或改色圖騰，也未改動正式遊戲 runtime。這是美術配置示意，非遊戲截圖。
