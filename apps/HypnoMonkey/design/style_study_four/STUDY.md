# 催眠猴：使用者選定四款的重新拆解

使用者所指是六張接觸表按列閱讀的前四張：**Chaos Crew 2 → Donut Division → Dr Zappo → Red Rascal**。先前誤讀成候選網頁的編號；Toshi Ways Club 排除。本次重新閱讀四款的完整盤面與角色／圖騰局部，未將競品圖交給生圖工具。

## 1. Chaos Crew 2

實際畫面：左右角色有不同身形和手部任務；細長身體、下垂肩、鬆腿與大鞋形成整個動作輪廓。符號混合手繪標記和具體物件，重要物件有色卡，安靜的標記則直接靠負形與墨色工作。飽和色集中在符號和功能，不鋪成單一高彩度盤底。

前版問題：以表面歪線和大笑頭像代替完整造型；所有圖騰都被做成同等亮度、同等厚框的物件貼紙。

學到的要求：先看無裝飾的身形、手勢、輪廓負形；圖騰可有清楚的高低權重。街頭題材、武器與夜景不是本款要沿用的主題。

## 2. Donut Division

實際畫面：角色表情很省，墨鏡、鬍形和嘴角配合高低肩與休息站姿便有性格；場景透視、影子和較低對比把街道往後放。紙／杯、警燈、交通錐和甜甜圈有不同結構與明暗，並非全套一樣的平塗貼紙。

前版問題：把「少色」當作「畫得像」，背景只有平面帳篷排排站；人物被框進頭像卡，沒有站立重心或與場景互動。

學到的要求：角色放回場景，有身體重心及可讀的表演；背景有形體、透視和空間。道具材質可以不同，不能用一個通用高光套全套，也不能因為怕 AI 就把所有明暗硬刪掉。

## 3. Dr Zappo

實際畫面：博士、猴子和左側角色的頭身、口鼻、髮形、服裝與站姿各不相同；猴子與主角有明確的視線及姿勢關係。盤框是裝置，有按鈕、夾具和接合，與周圍建築／道具屬於同一個世界。

前版問題：用長下巴、翹鬍鬚和紫眼當作個性；紅金框、角色卡片、票亭與盤面像四個無關模板。

學到的要求：讓角色的任務和道具形成表演。催眠師手指必須確實碰到鏡框，助手要確實拿著懷錶；盤框做成可構造的舞台票亭，不憑空浮著。保留原創猴子，不能變成參考的黃臉博士或紅猴。

## 4. Red Rascal

實際畫面：角色是完整、誇張、有動作方向的老動畫人物；背景遊樂場用透視、大明暗塊和不同層次構成空間。盤框的棚布、木邊、地面與建築都能在同一個場景解釋。一般符號相對安靜，亮色特殊符號才跳出。

前版問題：把「復古馬戲」只畫成幾條帳篷條紋，所有主色同樣飽和；沒有前中後景，角色又是平面大頭貼。

學到的要求：馬戲世界先成立，再把盤面放進去。場景可以有有控制的繪畫明暗；強色與特效留給表演重點。黑夜、惡魔和恐怖元素不是催眠猴必須照用的內容。

## 共同結論與本次小樣

- 這四款的個性來自造型、表演和世界觀整合，沒有共同的固定七色色票。取消先前以全圖量化成七色作為風格成功標準。
- 不再附上被否定的舊角色圖要求局部修飾；新小樣從文字設計重新開始。舊素材保留作比較，不回報為定稿。
- 小樣驗證完整站姿、手碰鏡框、角色／盤面／地面關係、物件材質差異與中性盤底。不是正式遊戲截圖、已完成的 source split 或 Spine 交件。
- 主方向是彩色動畫漫畫；四款各有可學的決策，不將四套視覺元素機械拼貼在一起。
