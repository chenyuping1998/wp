# HotMiami store tile layers

- `HotMiami-BG.png`: 1024x1024 opaque background.
- `HotMiami-FG.png`: 1024x1024 character foreground with transparent alpha.

The two files are aligned and contain no game title, provider name, or other
baked-in lettering. Copy them to `upload/HotMiami/thumbnail/` when assembling
the submission package; the provider logo remains a separate upload asset.
