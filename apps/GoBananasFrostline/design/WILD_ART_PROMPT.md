# W 家族出圖規格 — Frostline 極地版

盤面上**最後一批**還是叢林素材的圖。其餘 12 張已於 2026-09-14 換成極地版
（見 `FROSTLINE_ASSET_TODO.md`），所以現在一排冰藍符號裡只有 W 是暖色的軍綠猴子，
在 118px 的實際尺寸下非常顯眼。

交付格式、底板規則、打光規則**完全沿用 `FROSTLINE_ASSET_TODO.md` 第一節**，
不要另訂一套——W 的底板必須和 `h1`–`h4` 同一群（暗板岩藍、冰藍內斜角），
否則它會是全盤唯一長得不一樣的格子。

## 1. `w.png` — 極地版大猩猩士兵

現在是：軍帽＋護目鏡、叼著金香蕉、橄欖綠軍裝、黃銅底板。

要改成：**同一隻大猩猩**，換冬裝。

- **毛邊風雪帽**（連耳護），**雪地風鏡推到額頭上**——推到額上而不是戴著，
  露出眼睛，表情才有戲。這是整個系列處理「頭部配件蓋住臉」的既有解法。
- 叼著的**金香蕉保留**，但**結一層霜**。那是這個系列的識別物，不要拿掉。
- 軍裝改**厚呢大衣／毛領**，橄欖綠 → 深板岩藍灰。
- 呼氣的**白霧**可以有，但**不要多到糊掉臉**。
- 底板：同 `h1`–`h4` 的暗板岩藍＋冰藍內斜角。

**這是全盤最重要的一張**，主體要比其他符號更突出一點。

## 2. `wx.png` — 整輪 WILD 面板（1:5 直幅）

現在是：金柱＋全身軍裝猴子。

要改成：**一整根凍住的冰柱，裡面封著那隻大猩猩**。

- 半透明藍冰的柱體，**內部有氣泡與裂隙**，猴子的身影在冰裡若隱若現——
  不是站在冰前面，是**凍在裡面**。
- 上下兩端要能接到盤面邊緣，不要畫成一張獨立的卡。
- 「WILD」字樣**不要畫進去**：遊戲不在這張圖上疊字，但盤面上下會有框件，
  畫了會被切。
- 邊緣要有**折射亮邊**，讓冰有厚度，不是一塊藍色玻璃。

> **這張和 `ExpandingWilds.svelte` 綁在一起。** 那個元件目前畫的光暈、倍率徽章環
> 和中獎外框都是**金色**，因為現在的面板是金的。`wx.png` 一改成冰，那三處也要
> 一起改成冰藍——程式裡已標註。買轉卡上的金柱同理（`generate_mode_cards.mjs`
> 的 `reelLock` 漸層），它畫的就是這張面板。**三者要同一批動。**

## 3. `cudgel.png` — 揮舞的道具（透明背景）

現在是：金香蕉（孫悟空金箍棒的路數）。

要改成：**結霜的金香蕉**，或**一根冰柱狀的棒子**。兩者都可以，前者保系列識別度、
後者更切主題——**建議前者**，因為金香蕉是這個系列的招牌。

- **透明背景**，不是鐵板。
- 不要把光暈烤進去：那會為某個背景打光，換背景就錯，而且會撐大 bounding box。
  發光由程式加。

## 硬性規則（與其他 12 張相同）

1. 1024px 起跳，`w`/`cudgel` 正方、`wx` 1:5
2. `w` 與 `wx` **不透明**；`cudgel` **透明背景**
3. 不可出現任何文字、數字、金額或博弈字眼
4. 左上單一冷光，右下陰影
5. 底板暗色，**絕對不要白底板**
6. 主體置中，佔畫面約 70%（`wx` 除外，它是整根柱子）

## 拿到圖之後

丟進 `design/source/gen2_symbols/`（同名覆蓋），然後：

```bash
node design/generate_symbols_gen2.mjs "E:/stake/tools/gen"
node design/generate_mode_cards.mjs "E:/stake/tools/gen"
```

第一支產出 256px 與 spine（`w_fg` 會自動從 `w.png` 裁出來），第二支把新的 W
重新合成進買轉卡。舊的叢林版在 git 裡（commit `375b628` 之前），隨時可還原。
