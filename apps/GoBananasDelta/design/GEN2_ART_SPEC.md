## 1. 交付格式

| 項目 | 規格 |
|---|---|
| 尺寸 | **1024×1024**（最低 512×512）。遊戲內是 256×256，來源大才有銳利度餘裕 |
| 長寬比 | **正方形**。非正方會被補邊，邊框粗細就不一致了 |
| 格式 | PNG，不透明（整塊鐵板，不留透明區） |
| 命名 | 全小寫、無空格，見第 3 節表格 |
| 色彩空間 | sRGB |

> 上一批的問題：132–152px 且非正方。放大到 256 會糊，補邊會讓某些格子的邊框比鄰居細。

## 2. 顏色系統（**本文件最重要的一節**）

老虎機符號的辨識度不是「好不好看」，是**玩家在 0.3 秒的滾停瞬間，能不能分辨這格是什麼**。
規則只有一條：**同一階層的符號共用一種調性，不同階層之間必須用顏色一眼分開。**

### 2.1 階層與配色

| 階層 | 符號 | 主色 | 為什麼 |
|---|---|---|---|
| Wild | `w` | 角色膚色＋**橘** 配件 | 全盤唯一有臉的，形狀已經夠獨特，橘色配件負責在遠處抓眼 |
| Scatter | `s` | **高飽和金**＋紅緞帶 | 全盤**最亮**的一張。玩家在等的就是它 |
| 高賠 1 | `h1` | **紅** | 最高賠＝最搶眼的顏色 |
| 高賠 2 | `h2` | **綠** | |
| 高賠 3 | `h3` | **木棕＋自然黃** | |
| 高賠 4 | `h4` | **青藍** | |
| 低賠 | `l1`–`l5` | **無彩冷灰鋼**（全部一樣） | 它們是背景噪音，不該搶戲。靠**字形**分辨，不靠顏色 |

### 2.2 上一批的兩個撞色問題（重生時務必修掉）

- **`h1` 綠鋼盔 撞 `h2` 綠鳳梨手榴彈** — 兩個最高賠的符號同色，滾動時分不出來。
  h1 改走**紅**：鋼盔本體壓暗，配一枚大顆紅色軍階星／紅色貝雷帽，讓紅色佔主導。
- **`h4` 黃銅指北針 撞 `s` 金香蕉** — scatter 必須是全盤唯一的金色。
  h4 改走**青藍**：發藍鋼外殼＋夜光青色錶盤，金屬邊框壓成暗鋼。

### 2.3 硬性對比規則

顏色分得開還不夠，**明度也要分得開**——約 8% 的男性有色覺辨識障礙，只靠色相會失效。

- 主體與底板的**平均明度差 ≥ 30%**。深色主體配亮底板，或反之
- **瞇眼測試**：把圖縮到 64px 再瞇眼看，如果兩張高賠符號的色塊分佈長得像，就是失敗
- 低賠 `l1`–`l5` 之間不需要明度差（它們本來就該長得像），但**每一個字形的外輪廓要夠不同**

### 2.4 底板規則（所有符號共用）

底板是把 15 格串成一面牆的東西，**必須高度一致**，否則盤面會看起來破碎。

- 橄欖灰綠金屬，邊框取樣色 `#5f6459`–`#757d71`
- 四角各一顆鉚釘，邊緣一圈內凹陰影
- **邊框粗細所有符號一致**（因為盤面已經不畫格線了，符號的邊框就是格線）
- 四角略帶磨損，非正圓角
- **階層附加線索**：`h1`–`h4` 和 `w`/`s` 的底板加一圈**黃銅內斜角**；`l1`–`l5` 維持素鋼。
  這讓玩家不靠顏色也能分出高低賠

### 2.5 共通打光與質感

- 左上主光源，右下陰影，全套一致
- 整體偏暗、低飽和的軍事風；**只有主體的識別色可以高飽和**
- 金屬鏽蝕、刮痕、髒污。避免乾淨塑膠感、卡通描邊、外發光
- 主體置中，佔畫面約 **70%**，不要頂到邊框
