# 分層(部件)素材放這裡

一個符號一個資料夾,檔名和規則見 `docs/art-prompts-hot-miami-parts.md`(在 repo 外的
stake-engine 根目錄下)。

三條最容易做錯、做錯就整包重來的:

1. **每個部件都是 512×512,而且待在它在完整圖裡的原位** —— 不置中、不裁切、不縮放。
2. **被遮住的地方要畫完整**(手臂下的襯衫、輪拱內側、頭髮下的肩膀)。
3. **背景用純色鍵**(h1/h2/h3/c 用 `#00FF00`,h4/h5 用 `#FF00FF`),而且那個顏色
   不可以出現在圖裡。

每個資料夾還要一張 `_full.png`(部件疊起來應該長得跟它一樣),我用它驗證位置有沒有跑掉。
