# Treasure Monkey（海灘尋寶）— 動畫需求單

> **2026-10-18 使用者決定：玩法底座改參考 Capo Nostra**（5×4、14 線、Tommy Gun 整輪擴展 Wild、1×1／2×2／3×3 倍率框、三檔 FG、三階 Buy）。
> 畫風、角色、動作仍照 Le 系列（本單與 `cast_brief/`、`motion/`）。本單裡依茶樓底寫的玩法段落（W 收 P、計量表 4／8／12、P 金幣、Buy 名稱與次數）
> 之後要對到 Capo 的機制，**目前先不改**。

2026-10-18 開案草稿。美術見 `TREASURE_美術需求單.md`，音效見 `TREASURE_音效需求單.md`。
本單列出**每一個會動的東西**：誰動、什麼時候動、怎麼動、多久，以及要改哪支程式。

> 給執行者（Codex）：本款預定從 `PuttMonkey迷你高爾夫` 複製，**符號、背景、面板、大獎的演出元件都已經存在**，現在播的是高爾夫版本。
> 時間數字是目標值，可以 ±15% 調整到好看為止；Turbo 時程式會自動縮短，不用另外做（收分例外，見第 3 節）。
> **角色的動作不是茶樓底那 9 個 Spine 動作**，是 Le 系列量出來的動作表，第 1 節由 Claude 接，Codex 不用寫。
> 客製動作只寫在本 app，**不要改 `wp/packages`**。

---

## 0. 原則

1. **動作要節制、像專業動畫**：只動主角，不動邊框裝飾；演一下就長時間靜止，不要一直晃（使用者規則，晃個不停就是 AI 感）。
2. **擺動用彈簧感**：旗子、帽繩、尾巴、小紙傘都是「延遲、過衝、回彈」，不要等速。
3. **挖寶的節奏是「期待 → 爆發」**：探測器嗶嗶越來越快、停半拍、「噗」一聲才彈出金幣。每次只停一次，不然收集會拖。
4. **分工**：符號、背景道具、FG 面板裝飾、大獎牌匾裝飾都是 **mesh**（`src/game/meshWin/`）；兩隻猴子是**分層網格**（`layeredFigure.ts`），不是 Spine。
   讀取頁三格說明**不做網格**。
5. 不做呼吸光暈、不做全畫面白閃。

## 2. 符號網格（落地、待機、中獎）

程式位置：`src/game/meshWin/`。Putt 的骨架是 `puttWins.ts`，**換圖後新寫一支 `treasureWins.ts`**，依新圖量出本體與配件位置，`acts.ts`、`index.ts` 改 import 它。
換完符號圖先跑 `python design/make_jade_mesh_layers.py`，再跑 `node design/check_mesh_wins.mjs`。

| 符號 | 配件（會動的那一塊） | 落地（0.35s） | 待機小動作（盤面靜止時隨機） | 中獎循環（1.2s） |
|---|---|---|---|---|
| H1 寶箱 | 蓋子（以後緣為軸掀開） | 箱子壓扁回彈，蓋子被震開一條縫又關上 | 蓋子掀開一條縫、透出金光、關上 | 蓋子掀開 30°、金光一閃、關上（兩次） |
| H2 沙堡 | 塔頂小旗 | 沙堡落下時掉一小撮沙粒 | 小旗飄一下 | 小旗大幅飄、沙堡輕輕上下彈 |
| H3 海螺 | 殼口的泡泡 | 殼滾半圈回正 | 殼口冒兩顆泡泡 | 殼左右搖、泡泡連冒 |
| H4 椰子汁 | 小紙傘 | 汁面晃 | 紙傘轉半圈 | 紙傘轉兩圈、椰子左右搖 |
| W 阿寶叔圖章 | 帽繩 | 圓框砸下＋帽繩甩 | 瞇眼（換一格）或挑眉 | 圓框放大 8% 脈動、帽繩甩 |
| S 藏寶圖 | 捲起的那一邊 | 地圖拍下、捲邊彈開 | 捲邊被風吹得微微捲動 | 地圖攤開更大、紅 X 脈動 |
| P 金幣 | 無（整枚） | 「叮」彈一下（彈 2 次，第 2 次很小）、側翻一點再回正 | 很偶爾閃一道光（每次只一枚） | 見第 3 節（被收走） |
| L 小木牌 | 字（程式字） | 輕彈、繩子晃 | 不做 | 字發天空藍光一下 |

- **配件與本體之間不能有縫**；寶箱蓋掀開露底就是美術沒補畫，回美術修。
- 金幣上的倍數字**翻轉時要保持正向**（字綁在本體、不跟著翻）。

## 3. 收集演出（本款招牌，收分不受 Turbo 加速）

觸發：盤面停下後有至少 1 個 W、至少 1 個 P（`bookEventHandlerMap.ts` 的 collect 事件；元件 `BanditCollect.svelte`、路徑 `src/game/collectionMotion.ts`）。
Putt 現在是「球滾進洞」，改成下面的時間軸（每個 W 依序一次；第 2 個 W 起縮短 30%）：

| 時間 | 誰 | 做什麼 |
|---|---|---|
| 0 | W 格 | 圓框放大 1.12；MG 阿寶叔 `fishing_start`（縮到 0.9s）：探測器往前推出、掃過 W 的方向 |
| 0.1–0.5s | W 格 | 探測器指示燈（程式畫的小圓點）嗶嗶閃，間隔 160ms → 60ms 越來越快 |
| 0.55s | W 格下緣 | **沙坑噴開**：`sand_pit.png` 從 0 張開到格寬 0.6（0.15s），外圈噴起一圈沙粒；`tin_bucket.png` 從坑邊彈出來站好 |
| 0.7s | 每個 P | 依「離 W 由近到遠」排序，每顆間隔 90ms：先在原格**往下沉一點再「噗」地彈出**（像從沙裡跳出來）→ 沿拋物線**翻著飛**向小鐵桶（側翻、軌跡略帶弧度，不要直線） |
| 每顆進桶 | W 格 | 桶子被砸得往下壓一下、W 上方累計數字 +值（現有 `plate` 數字）；音效 `coin_in`（程式每顆加高 7% 音高） |
| 收集期間 | MG 阿寶叔 | `fishing_idle` 循環，身體往桶子的方向傾 |
| 全部進桶 + 0.2s | W 格 | 沙坑收合（0.2s）；阿寶叔 `fishing_end_hit`（往後一坐、舉起一枚金幣）；擬聲字彈出（`ComicPop`，字待限制字檢查） |
| 結束 | 盤面 | 被收走的 P 格**留原圖**（數學上 P 還在盤面），淡回 100% |

- 10 顆以上時間隔縮到 50ms，**總錯開上限 480ms、整段 ≤2.4s**；虛擬時鐘不受 Turbo 影響；清場會取消等待與動畫（照 Putt）。
- 飛行拖尾：`collect_bananas.png`（小金幣）＋沙粒。
- 事件金額由數學 book 決定，演出只負責好看。

## 4. 免費遊戲（觸發、轉場、升級）

### 4-1 觸發（3／4／5 張藏寶圖）

- 每張 S 落地依序亮（`scatter_1`～`5`）；第 3 張起其他 S 的捲邊開始大幅捲動。
- 觸發瞬間：所有 S 攤開放大、紅 X 一起閃；MG 阿寶叔 `reel_highlight` 的前半段（前傾盯盤面）；擬聲字「X MARKS THE SPOT!」。

### 4-2 轉場（`TransitionAnimation.svelte`）

Putt 是巨大高爾夫球滾入、停住晃、滾出。本款**沿用同一套路徑與旋轉**，主角換成巨大救生圈：

| 階段 | 時長 | 內容 |
|---|---|---|
| 進場 | 0.9s | 巨大救生圈（`transition_wipe.png`）從左滾入 |
| 停住（遮住畫面） | 0.38s | 停在中間時像浮在水上**上下漂兩下**（±6px、±3°），這時程式切 MG→FG 背景（`oncover`） |
| 離場 | 0.85s | 往右滾出 |

- 音效 cue 改名：滾動 `soundRingRoll`（`ring_roll.wav`）、停住 `soundRingSplash`（`ring_splash.wav`）。
- 進 FG 前阿寶叔播 `win_3`，不丟道具（本款沒有 `throwit`）。

### 4-3 FG 開場面板

- `fg_intro`（底板）＋`fg_intro_decor`（裝飾）：底板從下方彈上來（0.6s 帶過衝）；裝飾層用 `design/make_decor_meshes.py` 切成 mesh，落地晃一下之後就靜止，只留一個慢動作（例如貝殼上的小旗慢慢飄）。
- 同時 FG 小救 `welcome`。
- 換裝飾圖後**一定要重跑 `make_decor_meshes.py`**。標題字直接寫在面板上，**沒有標題底板、沒有上方布幕**。

### 4-4 計量表升級（4／8／12 個 W；`BanditMeter.svelte`）

Putt 是火山噴發。本款改成**浪捲過去**：

| 時間 | 內容 |
|---|---|
| 0 | 盤面變暗 20%；FG 小救 `fishing_start`（縮到 0.9s）：鏟子往前插進沙 |
| 0.2s | `chef_cut_in.png`（小救吹哨）從畫面下方彈入 |
| 0.5s | 畫面輕震 2px；`wave_sweep.png` 從盤面右側捲入，沿著要替換的那一排（10，之後 J、Q）由右往左橫掃（0.5s），浪頭經過的低分牌被「淹」過去（往下壓到 0.85、蓋上一層白泡） |
| 1.0s | 浪退回右側（0.3s），白泡散開時原地變成金幣（從 0.6 彈到 1.1 再回 1.0），每格間隔 40ms |
| 1.4s | 小救 `fishing_end_hit`；擬聲字；+10 轉的數字從計量表飛到 FS 次數 |
| 1.9s | 盤面恢復亮度 |

### 4-5 FG 結算

- `fg_total`＋`fg_total_decor`：黑板彈上來，裝飾層的金幣一枚枚從上方掉進畫面、堆起來（間隔 60ms）；小救 `dance_start` → `dance_long` → `dance_end`。

## 5. 背景動態（`src/game/meshWin/bgProps.ts`、`Background.svelte`）

Putt 的風車、恐龍、火山、遮陽傘、雲全部換成：

| 物件 | 背景 | 動作 |
|---|---|---|
| 海浪白邊 | MG／FG | 浪花往岸上推、退回（`drape`，6s 一次，**很小**） |
| 救生員椅的紅旗 | MG | 旗面飄（`sway`，±4°，3s） |
| 遮陽傘 | MG | 被風吹得晃（±3°，4s） |
| 海鷗 | MG | 每 12–20s 一隻從遠處滑過（不拍翅，只滑行） |
| 雲 | MG | 2 朵非常慢地往右飄（30s 一趟） |
| 燈塔光束 | FG | 光束慢慢掃過海面（8s 一圈） |
| 木棧道小燈串 | FG | 燈泡逐顆亮起繞圈（3s） |

- 每個物件要有美術交的獨立分件＋座標，t=0 與背景完全貼合；矩形互不重疊。
- 動得最多的只有海浪和旗子；其他都很慢或很久才一次（第 0 節第 1 點）。

### 背景記分板（Putt 的 `BowlingScoreboards.svelte`，已改成 HOLE 欄位，本款改名 `TideBoard.svelte`）

救生員站的潮汐黑板，5 欄「TIDE 1–5」，每欄寫該轉派彩倍數（粉筆字感）。新的一轉寫在最右欄、舊的往左推；大獎時該欄畫粉筆圈＋閃字 1.6s（字待限制字檢查）。邏輯照搬 Putt。

## 7. 大獎五階（`Win.svelte`、`BigWinFx.svelte`、裝飾層 mesh）

進場 0.9s、循環 2s、退場 0.5s（程式已有）。裝飾層由 `make_decor_meshes.py` 切開後各自動：

| 階 | 裝飾動作 |

| EPIC | 浪頭捲動（mesh 波動），金幣從浪頂往上飛出畫面 |

## 9. 驗收

- `pnpm build` 通過（含 `check_mesh_wins`、`check_types`、`check_assets`、`check_audio`）；角色另跑 `check_layered_cast.mjs`（待機 32s、三級反應 × 1／2／4 倍速）。
- 離線看人物：每個動作的峰值定格截圖，網格不摺疊、不翻面、手臂不像沒骨頭；探測器／鏟子每個動作都黏在手上；換件切換沒有跳位。
- 收集 10 枚金幣的整段 ≤2.4s；Turbo 時同樣正常速度。
- 連按 Spin 20 次，背景動態不累積、不卡頓。
- 交件附 `design/source/treasure/_anim/` 下的錄影或逐格截圖（收集、升級、轉場、角色三級反應）。
- 依使用者規則：最終實機驗證由使用者上傳 Stake Engine 執行，交件說明要**寫清楚哪些只做了離線驗證**。
