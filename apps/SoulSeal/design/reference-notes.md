低分賠付低到近乎象徵性。價值全押在 cash symbol 與 feature——
這是 Hacksaw 的一貫手法，本作沿用這個分配。

**Feature**（讀自 game info）

- `OFF THE HOOK!` — 4 scatter，15 free spins，帶 Marlin Progress Bar
- `PLENTY OF FISH IN THE SEA` — 5 scatter，10 free spins，所有馬林魚保底 5×，
  且每轉保底至少一隻馬林魚 + 一個漁夫
- `REEL IT IN` — Marlin Progress Bar 機制的來源
- Bonus buy 四檔：€6 / €100 / €100 / €400（bet €2 → 3× / 50× / 50× / 200×）

最低那檔 €6 的 bonus hunt 值得注意：它賣的不是 feature，是「進 feature 的機率」。
成本低到玩家願意連續按，是很聰明的留存設計。

## 2. 美術原則（可移植的部分）

### 2.1 框架是劇情道具

轉輪外框不是金屬邊或寶石框，是**船上的釣竿架**——真的釣竿、捲線器、繩索、
浮標、銅鈴、木欄杆。玩家看到的不是「一個 slot 介面」，是「站在船尾看著海」。

這是整套美術最值得學的結構性想法，且完全與題材無關，可以直接搬。

→ 本作：法壇。見 `art-bible.md` §4。

### 2.2 三層景深，中層刻意壓暗

| 層 | 處理 |
|---|---|
| 遠：天空、海、雲、遠處小漁船 | 低對比、亮、去飽和，帶空氣透視 |
| 中：轉輪窗（暗青綠木板） | 壓暗壓灰，把 symbol 推出來 |
| 近：船板、釣竿、繩索 | 最暗、最高細節，形成 vignette |

中層壓暗的關鍵：**不是純黑遮罩，是有材質的暗色**
（木板紋理 + 微弱水波光）。既拉對比又不讓畫面死掉。

→ 本作：青磚牆 + 燭光徑向漸層。

### 2.3 階級用材質區分，不用大小

1. 低分（皇家）：彩繪木板刻字，單一材質、單光源、色相編碼。
   造型矩形塊狀，穩定但無趣——**故意的**。
2. 中分（魚）：全繪製插畫，飽和度更高、有高光、有動態姿勢。
   剪影差異明顯（胖圓 / 扁菱 / 圓 / 細長）。
3. 特殊（漁夫 / 馬林魚 cash）：**外加一個容器**——紅相框、金牌匾、藍緞帶。
   有框 = 高階，這是最快讓玩家分辨階級的手法。

→ 本作：五行桃木牌 / 四妖 / 符紙與葫蘆光暈。

### 2.4 錢的顏色被獨佔

藍緞帶 + 黃字，是全畫面對比最強的一組，且**只用在金額上**。
畫面裡沒有第二個地方用這個組合。非常嚴格的色彩紀律。

→ 本作：符紙黃 + 硃砂紅。見 `art-bible.md` §2.2。

### 2.5 進度具象化成實體物件

收集條是頂部欄杆上排開的 12 個銀色漁夫像，第 5/9/12 格是金色 `+8FS` 徽章，
上方掛 `MIN X2` / `MIN X4` / `MIN X10`。

不是抽象進度條，是「排在架上的實體物件」。

→ 本作：頂端橫木上的 12 個符位。

### 2.6 演出克制，環境有生命

- 中獎只有黃色折線 + 中央白色描邊數字。沒有滿版粒子、沒有畫面震動。
  juice 全留給 feature。
- 環境有持續的低成本動畫：海鳥飛過、陽光閃爍、遠處小船上有人在釣魚。
  避免等待時畫面「死掉」。

→ 本作：香爐煙、燭火晃動、幡旗飄、遠景霧移、偶發紙鶴。

### 2.7 UI 與場景切乾淨

底部 bet bar 是唯一非劇情元素，深色半透明條。
BUY BONUS 是圓形黃鈕，孤懸左下，形狀跟其他 UI 都不同 → 最高視覺優先權，
且遠離 spin 鍵。

→ 本作照搬，圓鈕改成銅錢造型。
