# MUMMY MAYHEM — 節奏與動態需求單

給執行者（使用者或 Codex）。範圍只限 `wp/apps/MummyMayhem木乃伊`，不要改 `wp/packages/*`。
這份規定**每個事件幾秒、誰在動、聲音打在哪一格**。美術見 [MUMMY_ART_REQUIREMENTS.md](MUMMY_ART_REQUIREMENTS.md)，音效見 [MUMMY_AUDIO_REQUIREMENTS.md](MUMMY_AUDIO_REQUIREMENTS.md)。

數值來源：
- **Scarab Wheel**：2026-11-06 錄影 10 fps 逐格量測（`E:\stake\proposals\輪盤雙機制\輪盤雙機制_整合研究.md` §2.2）
- **Sun Wheel**：東海龍王 `RouletteView`、`Roulette`、`GameTimeAsseter` 設定值＋錄影（同文件 §1.3）
- **獎圖、人物、背景**：`wp/.claude/skills/slot-motion-recipes`（拆解 Pragmatic Play 量出的數字）
- 程式裡的時間表：`src/game/wheels.svelte.ts`（`FG_WHEEL_MS`、`ROULETTE_MS`）、`src/game/constants.ts`（轉輪）、`src/game/winLevelMap.ts`（大獎）

## 0. 原則（使用者定過的，每一節都適用）

1. **動態要節制、像專業動畫**：只動主角，**盤框、邊條、裝飾不動**；演一下就長時間靜止，不要一直晃（會有 AI 感）。
2. **idle 不是 win 的慢版**：幅度小一個數量級，一般距離幾乎看不出在動，只有光在呼吸。
3. **動作有預備、有停頓**：先往反方向（先蹲才跳、先退才衝），到最高點**停住**（停的時間常比動的時間長）。
4. **跟隨感靠錯時**：鏈上每一節同值、晚 0.03–0.1 s，不靠物理亂甩。
5. **不要小星星粒子、硬邊光環、方框特效**；光效用柔和背光、光澤掃過。
6. **Turbo 和自動轉一定不能卡**：任何「等玩家按」的地方都要能自己往下走。

## 2. 連線與中獎符號

### 2.1 連線（`WinLines.svelte`，已做）

- 全部中獎線**同時**畫，線由左往右跟著一軸一軸點亮，每軸間隔 **90 ms**（快版 40 ms）
- 線是白色細線＋淡淡的暖色外光（不要彩虹色），六條以上自動變細
- 每條線**起點那格**印這條線的金額；同一格起頭的線合併成一個數字
- 沒中的格子壓暗（`WinScrim`，62%）
- 最後一軸點亮後至少再停 **950 ms**，讓符號的 win 動畫演得完；Turbo 只停 220 ms
- 一局結束後，閒置時每 1.6 s 重播一次本局的線（主遊戲才重播）

### 2.2 獎圖動畫（5 層結構，照 slot-motion-recipes）

每個獎圖：Normal（idle）／Blurred（轉動中）／Win／共用的中獎框／共用的消失特效。**狀態靠開關圖層，不靠混合。**

**win 動畫：1.5 s、三拍**（0.13／0.47／0.83／1.2 s），每個高分照這個時間表，只換「衝出框」的方式：

| 時間 | 動作 |
|---|---|
| 0–0.14 s | 先縮（預備）scale 1 → 0.95 |
| 0.27 s | 細節（眨眼、蓋子微開） |
| 0.41 s | **第一次衝出框**：主體上移約格高 5%、scale 1.08，頭／蓋子越過上框 |
| 0.6 s | 回框 |
| 1.1–1.23 s | 第二次衝出 |
| 1.5 s | 回到 idle 姿勢（首尾同一格） |

各符號的「戲」：

| 符號 | 衝出框時做什麼 |
|---|---|
| H1 貓臉石棺 | 棺蓋往上彈開一條縫，縫裡一雙貓眼眨一下；蓋子落回時整個棺身壓扁再彈 |
| H2 卡諾卜罐 | 貓頭蓋子跳起來轉 15° 再落回，罐身跟著擠壓伸展 |
| H3 繃帶毛線球 | 球滾一下，**甩出去的那條線**用 shear 甩動（越末端角度越大，子節晚 0.07 s） |
| H4 繃帶魚骨 | 魚尾甩兩下、魚頭張嘴，尾巴的繃帶蝴蝶結跟著晃 |
| W 木乃伊貓 | 露出的那隻眼睛 wink，臉上一條繃帶「啵」彈開再縮回，耳朵抖一下 |
| S 黃金貓神面具 | 不跳；光澤由左上掃到右下（0.4 s），眼線的綠松石亮一下 |
| L1–L5 | 只做整體的跳＋擠壓伸展：先蹲 y −4%、跳 +11%、落、小彈；scale 在 (0.88, 1.04) 和 (1.06, 0.91) 間交替 |

**idle**：位移 1–2 px、光只到 12% 的呼吸光；**多數時間完全不動**，每個符號隨機每 8–15 秒演一次極小的動作（石棺眼睛眨一下、毛線球的線晃一下）。

**落地**：只做一件事——落地曲線（y 0, −15, +5, −10, +3, −5, 0；scaleY 0.85 → 1.05 → 0.90 → 1.03 → 0.95 → 1，0.75 s）或 Spine 落地，**兩個疊起來會抖**。

**中獎框**：共用一支，0.3 s 序列，跟 Win 一起開；框是柔和的砂岩光邊，不要方框描邊。

## 3. 吉祥物：木乃伊貓

骨架用 `wp/tools/mascot-rig` 正面模板做（套版骨架），動作庫就是模板的 8 個，**不另外手 K**。換圖表情（眨眼、大笑）由遊戲端換 `head` 圖。

### 3.1 事件 → 動作

| 遊戲事件 | 動作 | 長度 | 備註 |
|---|---|---|---|
| 平常 | `idle` 循環 | 3.2 s | 呼吸、尾巴慢擺、耳朵；**每 2–4 個循環**在循環邊界換一次眨眼頭（0.15 s） |
| 進入遊戲、閒置超過 20 s | `wave` | | 外側那隻手（離盤面遠的那隻） |
| 期待（差一顆 Scatter） | `point` | | 盤面側的手指向盤面，停在指的姿勢直到停輪 |
| 期待落空 | `disappoint` | | 聳肩攤手；**30% 機率**加一次 `bandage_pop`（臉上繃帶彈開） |
| 一般中獎（≥ 5× 押注） | `laugh` | | 換大笑頭；小於 5× 不演，避免一直動 |
| FG 觸發、Scatter 三顆以上 | `cheer` | | 換大笑頭；跳到最高點時繃帶尾巴甩出 |
| Scarab Wheel 升起 | `point` | | 指向盤面下緣的拱，結果飛進中央時收手 |
| Scarab Wheel 轉出 12× 以上 | `laugh` | | |
| Sun Wheel 出現 | `throw` | | 把一個太陽圓盤「丟」進畫面中央：事件 `release` 那一刻太陽輪開始出現（§5 的 0 s） |
| Sun Wheel LEVEL UP | 不演 | | 他在暗幕後面，不搶戲 |
| 大獎跑分 | `dance` 循環 | 1.6 s | 跑分結束回 `idle` |
| 觸頂 wincap | `cheer` → `dance` | | |

- 反應動作用一次性播放，**另外排一個 reset 在動作長度後切回 idle**，不依賴 Spine 的 complete 事件
- 混合時間 0.12 s
- 一次只演一個反應；正在演 `cheer`／`throw`／`dance` 時不被打斷，其他可以被新的反應蓋過
- **目前的 `Mascot.svelte` 用的是 Boomana 的動作名**（`chestbeat`、`throwit`、`nod`、`flinch`、`alert`、`glance`），換骨架時要改成上表的 8 個名稱

### 3.2 大小與位置

- 站在盤面**右側**，臉朝盤面（盤面在他的畫面左邊，`mascot.json` 的 `reels: "left"`）
- 依側邊空間縮放；直式手機側邊不夠時**不畫**，不要硬縮到很小

## 4. Scarab Wheel（FG 倍率輪盤）

**每個 FG 有連線的局都會播一輪，沒連線的局完全不出現。** 一場 FG 會看到 5–8 次，所以節奏要俐落、要耐看。

### 4.1 時間表（`FG_WHEEL_MS`，程式已照這個做）

自動轉（非 Turbo）時間照「一般」欄，只有按鈕在 250 ms 後自動按下。

| 段 | 一般 | Turbo | 畫面 | 聲音 |
|---|---|---|---|---|
| 停輪後等待 | 300 ms | 120 ms | 盤面靜止，**不先畫連線** | |
| 盤面變暗＋拱升起 | 300 ms | 160 ms | 拱從盤框下緣的小圓牌放大成半圓（scale 0.5 → 1，ease-out） | `scarab_rise` |
| 等按鈕 | 玩家按下為止，最長 3000 ms | 250 ms 自動按 | 拱頂出現聖甲蟲金幣按鈕，輕微呼吸（scale ±8%，週期約 1 s） | `scarab_button_idle` loop |
| 按下 | 300 ms | 120 ms | 金幣碎開、指針淡入 | `scarab_press` |
| 格子帶轉動 | 3900 ms | 1200 ms | 格子沿拱捲動，ease-out 減速；**停點超過 0.18–0.30 格再退回**（不要正中停死） | 每過一格 `scarab_tick` |
| 回正 | 200 ms | 100 ms | 退回到結果格 | `scarab_stop` |
| 其他格變暗 | 200 ms | | 只有結果格亮，其他壓到 45% | |
| 停頓 | 300 ms | 200 ms | （讓玩家看清楚停在哪） | |
| 結果飛進中央 | 300 ms | 200 ms | 結果格的數字浮起、放大 1.9 倍、沿弧線飛進圓牌 | `scarab_fly` |
| 圓牌換數字＋金光環 | 300 ms | 200 ms | 數字換成新倍數、圓牌放大 1.25 倍、金光環一閃 | `scarab_mult_1/2/3`（依值） |
| 停留 | 900 ms | 350 ms | | |
| 拱縮回 | 300 ms | 200 ms | 縮回盤框下緣的小圓牌，盤面恢復亮度 | `scarab_sink` |
| 畫連線 | | | 線上金額已經乘好 | `line_draw` |

一般模式從停輪到畫線約 **8.0 s**（錄影實測 8.0 s，其中選擇 0.7 s）。Turbo 約 2.8 s。

### 4.2 主遊戲激活時（SCARAB5／SCARAB10）

同一套 Scarab Wheel 演出也用在主遊戲：激活 SCARAB5 時有連線的手、SCARAB10 時每一手，停輪後都先轉輪盤再畫線。差別：
- 圓牌每一手從 1× 開始（不累積）；激活期間圓牌一直停在盤框下緣
- 現在時間表跟 FG 一樣（約 8 s）。SCARAB10 每手都轉，**一般速度下每手要 8 秒以上**，之後可能要給主遊戲一套較短的時間（例如省略等按鈕、轉 2.5 s），這點待定

### 4.3 細節

- **格子帶**：印的值有 2、4、6、8、10、12、14、16、32×，**比目前倍數低的值也會印出來**（錄影也是），只是不會停在指針下；大小值交錯排，大值永遠夾在小值中間，才可能出現「差一格就 32×」
- **差一點**：約 20% 的時候停在結果格靠近大值的那一側邊緣（`stopOffset` 的做法，Deadwood 已驗證）
- **tick 聲**：每過一格一次，所以一開始很密、越來越稀，減速感自己出來；同一幀只播一次
- **平常**：FG 期間圓牌一直停在盤框下緣（縮一半），顯示目前倍數；倍數改變時圓牌輕輕彈一下
- **再進 FG**：倍數從 1× 開始；FG 結束時圓牌跟著場景一起收掉
- **續玩**：從 book 最後一個 `multiplierWheel` 還原倍數，不重轉（已做）

### 5.2 Turbo／自動轉

倒數縮到 2 秒、每格 0.5 s；轉 1.8 s、回彈 0.4 s；升級彈出 0.7 s；跑分 0.6 s；停留 0.7 s。整段約 6–7 s。

### 5.3 細節

- **指針轉、盤不轉**（龍王就是這樣）。盤面固定，玩家看得清每一格
- 四級的配色：黎明綠 → 上午藍 → 正午紅 → 神聖紫金；換級時外框光暈換成該級的 `ring_glow_lvN`
- 最大值永遠在正下方、LEVEL UP 在正上方（第 4 級正上方是 2000×）；格子排法照龍王，大小交錯
- 標題牌 `SUN WHEEL` 在盤上方，進場時先底板（0–0.33 s 跳到 1.11 再回 1.0）、再字、最後裝飾
- 吉祥物在暗幕後面，不演
