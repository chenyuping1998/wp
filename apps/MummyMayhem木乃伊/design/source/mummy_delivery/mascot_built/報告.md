- 流暢度：spine-generator 的檢查（頓挫、停頓、折角、循環接縫），80 以上就順。
- 網格摺疊：只算蓋到圖的三角形；摺疊（翻面）> 0 會看到鋸齒，擠扁（面積 < 25%）多半在關節內側、正常。
- 手追不上：IK 手離動作規劃的位置多遠（扣掉柔化 IK 在原圖就有的距離），以臂長計；超過 3% 表示動作要的伸展超過這隻手臂，手會停在半路。
- 腳底滑動：腳的 IK 目標沒動時，腳踝最多移動幾 px；超過身高 0.4%（這隻是 5.2 px）看得出腳在滑或浮起來。
- 第一格離原圖：只看循環，遊戲從靜態圖切進待機時會跳一下的角度。

## 比例與關節

- ✓ 手臂長度、手肘膝蓋彎度、脖子方向都沒問題
- ⚠ leg-l：腿畫得幾乎打直（98.5% 腿長），IK 柔化只剩 4.4 px；骨盆往上或傾斜時腳會離地
- ⚠ leg-r：腿畫得幾乎打直（98.5% 腿長），IK 柔化只剩 4.4 px；骨盆往上或傾斜時腳會離地

## 骨架

- 30 根骨：脊椎三段、鎖骨、手臂／腿各兩節＋手掌腳掌、手肘膝蓋半角輔助骨、尾巴 2 節、4 個 IK 目標
- 約束：手腳 IK（有 softness，不會啪一下打直）、4 個半角輔助（transform）；物理已烘成關鍵影格，遊戲不需要跑物理
- 9 塊網格、3096 頂點、5364 三角形（格距 18 px）
- 手臂：要把手放到定點的動作用 IK（laugh），其餘都是 FK（那段動畫把手臂 IK 的 mix 設 0，手臂跟著肩膀走）

## Spine 4.2.74 輸出（給遊戲）

- `game/mummyCat.json`、`game/mummyCat.atlas`、`game/mummyCat.png`（縮放 0.5）
- 用 spine-core 4.2.74 載入、逐格重播 422 格：骨頭位置最大差 1.4e-3 px、網格頂點最大差 1.8e-3 px、左右鏡像（skeleton.scaleX = -1）最大差 0.0e+0 px；atlas 每個圖都有對應區塊
- 事件：point（指出去那一下）、release（丟出手）、takeoff／land（歡呼起跳、落地）

放進遊戲（assets.ts）：

```ts
mummyCatMascot: {
	type: 'spine',
	src: {
		atlas: new URL('../../assets/spines/mummyCat/mummyCat.atlas', import.meta.url).href,
		skeleton: new URL('../../assets/spines/mummyCat/mummyCat.json', import.meta.url).href,
		scale: 1,
	},
},
```
