# DJ 空中刷碟預覽

刷碟位置在腹部正前方：上臂收向內側、手肘彎曲、手腕反向轉回，手指朝前下方。前後推拉搭配手掌透視縮放；不將整條手臂平伸向身體側邊。位置回歸檢查會確認刷動期間手腕維持在軀幹中心附近。

`dj_scratch` 是 3.2 秒單次動作：抬手、約 125 BPM 往返刷動、收手，身體與頭部配合節奏。開發模式 `?artReview=1` 的「人物：DJ 空中刷碟」按鈕可播放，結束後返回選定的待機動作。

新版補上抬手前反向準備、收手時微小延遲回彈、軀幹重心轉移、頭部反向延遲和空閒右手的節拍回應。既有前臂推拉與五指相位保持不變；`djStroke` Spine 標記固定在 0.60、1.08、1.56、2.04 秒。待機與飾物建議使用 `club_idle` + `club_flutter`，細節見 `CLUB_MOTION.md`。

手部使用新繪製的透明張手素材 `source/monkey_neon/dj_hand_master.png`，輸出成獨立 atlas page `dj_hand.png`。手腕加上五指各兩節，共 11 根骨骼；食指與中指反相微彎並縮短指尖，呈現交替按壓，其餘手指保持輕微彎曲。這是二維網格變形的手指動作，沒有完整三維指關節旋轉。

DJ 期間使用從袖口到五指的一整片連續網格，隱藏原本的握拳前臂。近袖口兩排頂點固定在上臂骨骼，往手掌逐步轉交權重；推拉位移由前臂骨骼帶動，不再將手掌切片單獨平移。這避免了前臂與手根分離，以及舊前臂裁切邊緣露出。張手與握拳在 180ms 內交叉淡化，動畫結束或被其他動作中斷時會還原原本手臂、顏色與附件。

驗證會同時播放 `flutter` 飾物軌與 200ms 動作混合，以 60fps 檢查袖口錨點不漂移、網格面積不低於原始的 20%，並確認回待機後原手型不殘留透明度。此版本供動作評審使用，尚未接入遊戲事件或加入唱盤道具、音效。

重新生成：

```powershell
node design/prepare_dj_art.mjs
node design/adapt_iron_idle.mjs
node design/check_neon_spine.mjs
```

生成工具需支援直接載入 TypeScript 的 Node.js。完整角色生成流程 `generate_monkey_spine.mjs` 也會套用此動作。驗證工具會以遊戲的 Spine runtime 在 60 fps 檢查網格反轉、起終點還原、腳部漂移及動作中斷後的附件還原。
