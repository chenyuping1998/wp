# 霓虹動作驗收

開啟本機 `http://127.0.0.1:3019/?artReview=1`，點「播放整段演出」。這是無交易的開發預覽：刷碟 → 起轉與逐軸停輪 → 同一列得分 → 單軸蓄力、爆炸與揭示 → 新獎圖動作。用這條連續流程檢查段落銜接，各別按鈕保留供局部檢查。

新增「人物＋背景連動」：先看律動待機與環境燈光，再刷碟，最後收勢回待機；工具會自動收合以露出舞台。「切換場景」依序展示夜街、屋頂、金庫並切換對應音樂。

角色現在預設為 `club_idle`，配上獨立 `club_flutter`，依場景音樂採 105／128 BPM 播放。完整刷碟仍是 125 BPM／3.2 秒，保留輕快版音效與四個刷動時點。一般遊戲的閒置導演每 8–12 秒安排小幅看盤或點頭，完整 DJ 表演間隔 24–32 秒；轉輪、得分、選單、舞台隱藏和背景分頁都會清除待演排程，恢復後重新等待。手動美術驗收模式停用自動動作，方便逐項比較。

本次修正：

- DJ 改成袖口至五指的連續網格，根部固定上臂，手腕與手指逐步交接權重；保留正前方推拉。
- 張手／握拳採 180ms 交叉淡化，回待機採 200ms 混合；已被中斷的動作完成事件不能搶回控制權。
- 轉輪模糊跟隨真實位移速度，換帶時重新取樣，減速先恢復清晰，停止歸零。
- 移除轉動時額外的 3% 拉長，停輪後用 180ms 接入待機呼吸，避免輪廓與尺寸跳動。

驗證：

```powershell
node design/check_neon_spine.mjs
node design/check_mascot_director.mjs
node design/check_reel_motion.mjs
node design/check_types.mjs
node design/check_mesh_wins.mjs
node design/check_idle_land.mjs
```

骨架檢查涵蓋動作專用附件、袖口固定點、混合軌、網格反轉、回待機與中斷還原。轉輪檢查涵蓋 30/60fps 一致性、換帶與停輪清晰度。這些檢查不能代替美術觀感驗收；新手型仍是現有畫面的 2D 網格改作，透視角度有其限制。
