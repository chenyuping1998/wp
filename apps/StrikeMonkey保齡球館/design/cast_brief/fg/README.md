# Sushi Monkey — FG 角色需求單

使用者 2026-10-05 已選 #7 香蕉猴：我們自己的全身站姿 Spine，含 idle／flutter／nod／cheer／chestbeat／throwit／flinch／alert／glance。

角色：年輕精瘦的另一隻猴子壽司師傅。畫風承接 ../../../ART_BRIEF.md 的 §0。

- 角色立在盤面右側，臉與身體向盤面；全身含雙腳，兩臂自然垂下、肘微彎、前臂與軀幹至少留 48px（1024 寬）。
- 雙手自由，不能持刀、貼大腿、插口袋；頭巾／衣袖／圍裙可作次要動作件。
- 交透明 RGBA 原稿，建議 1024×1668；骨架與新圖比例一致後再切，不沿用舊 CUTS。
- 可交一張完整圖或 24 層原畫，陰影與描線都遵守 §0；關節重疊並補被遮住的衣料。
- 新图：head／torso／兩邊上臂、前臂、手／兩邊大腿、小腿、腳；配件另件。
- throwit 道具 = 小壽司盤，獨立透明圖。
- MG／FG 是兩個不同角色；同光向、腳底線，頭頂差≤5%。
