# Pickle Panic MG — 自有 #7 製作需求

## 0. 畫風與測量

使用者選定粗墨線美式漫畫。原生媒材：美式科幻漫畫、迷幻廣告、餐館點單票與紙帽印刷。外線約內線兩倍、圖騰外線約畫布3%，以寬筆刷與粗麥克筆形成胖瘦不均的墨線；大面積偏斜實黑陰影、平塗油墨，每個形體最多兩個色調加墨黑。造型故意不對稱，但輪廓與關節要有目的，不是均勻抖線。乾筆斷墨只在少數邊角，不鋪均勻顆粒。不要3D、亮面金屬、漸層、光暈、均勻皮膚亮條、微細紋理、光滑玩具卡通；不生成假網點與均勻紙紋。角色眉毛、齒列、帽子與肚形須偏斜、誇張、粗獷；圖騰大色塊優先，不以大量芝麻、肉粒、萵苣細線等細節填滿。若要印刷質感由统一後製套用。

固定方向色：#6A9F35酸黃瓜綠、#31572C橄欖陰影、#FFF0CF奶油紙白、#E9B83E芥末黃、#C84A36番茄紅、#20231D墨黑；前景圖騰與人物仍用上述色系。背景獨立冷色盤：#D8D2ED淡薰衣草紫、#C6DFEA冰藍、#8583B5灰紫、#514567暗李紫、#D78F92粉紅、#252735墨色。背景細節與飽和度低於圖騰；角色身後不得有綠／黃大塊、罐體或管線切過外輪廓。高密度道具偏左、角色右側留安靜明亮藍紫壁面。避免用單純粗白外光補救同色背景。紅重点用于特殊符號與FG升級。

風格測試包含H1、Wild、低分票卡、背景、MG人物，放入真實盤面及70px灰階表、200px大廳尺寸。樣張核准後記錄colors95／soft／palette-fit數字並設定相對閘門；目前尚未核准，不把預設寬鬆閘門當成驗收。

字体：既有本機Bungee標題、Archivo長文、Anton數字；繪製字與執行期字同一語言，所有數字由執行期排版。


人物朝左，完整雙手自由垂下；腳底統一，兩位各自量關節與切層。使用自有九段動作，不配送研究骨架或素材。裁切後驗證不漏像素、權重和接縫，再在實機確認idle、cheer、chestbeat、throwit峰值。
