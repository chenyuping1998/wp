# Pickle Panic — 美術／動畫／音效需求單（2026-10-13）

來源：2026-10-13 實機檢查（16:9 桌面＋375×812 手機，跑過一般轉、Diner Service 全程）。
程式能修的部分已同日處理（見文末「已用程式處理」），本單只列**需要新產出**的東西。

標準：**資深美術＋資深動畫師的交件程度**。意思是：

- 每張圖先過**剪影與明度**，再談顏色：70px 灰階表上能分辨，200px 大廳尺寸能讀。
- 凡是會動的東西都**分層交件**，層的切法由動作決定（關節、軸心、遮擋要補畫），不是畫完再硬切。
- 動作要寫清楚**關鍵影格、毫秒、緩動、軸心、擠壓伸展比例**；有預備動作、主動作、跟隨／重疊、收尾，不是單一 tween 放大縮小。
- 驗收用數字：量測閘門、alpha 邊盒、時間碼，不靠「看起來還行」。

畫風、色卡、量測閘門一律沿用 `ART_BRIEF.md` §0（粗墨線美式地下科幻漫畫、外線約內線 2 倍、每形體最多兩色調＋墨黑、無漸層、無 glow、無均勻顆粒）。
新圖量測閘門：colors95 ≤ 140、soft ≤ 38%、palette-fit ≥ 60%（`design/production_style_metrics.txt` 同一套）。
**文字與數字一律不烘進圖**（Logo 例外），由執行期排字。

## A. 小圖 10 / J / Q / K / A（P0）

**目的**：小圖要有「畫過」的質感，但價值感**必須低於** H1–H4。

**美術方向**（建議，可提案替代）：同一家族的「出餐口小物」，每張一個字、一個小道具，字是主角：

| ID | 字 | 道具 | 主色（§0 色卡） |
|---|---|---|---|
| L1 | A | 芥末擠瓶，A 字用芥末擠出來 | #E9B83E 芥末黃 |
| L2 | K | 番茄醬瓶，K 字用番茄醬擠出 | #C84A36 番茄紅 |
| L3 | Q | 酸黃瓜切片（圓片）當 Q 的圈 | #6A9F35 酸黃瓜綠 |
| L4 | J | 叉子／牙籤串酸黃瓜，彎成 J | #31572C 橄欖 |
| L5 | 10 | 「1」是醃漬條、「0」是酸黃瓜切片 | #8583B5 灰紫（與 FG 升級的紅分開） |

- **字形**：手寫粗墨字母，不是字型描邊；筆畫寬約字高 18–22%，外線約內線 2 倍。字的輪廓要一眼讀出字母，道具是點綴，不能蓋過字。
- **層級**：不加底卡、不加紅；彩度與明度對比**低於** H1–H4（量 contrast，交件附數字）。
- **底板**：保留現在的點單紙籤 `low_label.png` 當格底（大圖也用同一張，盤面靠它成格）；字圖是**透明疊層**。
- **規格**：每張 512×512 透明 RGBA，四邊 ≥ 8% 安全邊，ink 邊盒約 0.62–0.70 畫布（現在大圖 ink 是 0.82，小圖要明顯小一號）。
- **動畫分層**（給 E 用）：字身、道具各一層；擠瓶類另交「擠出物」一層。
- **檔名**：`l1_a.png` … `l5_10.png`，原稿 ≥ 1024 再降採樣。
- **驗收**：70px 灰階表五個字互相分辨、與大圖分辨；盤面截圖（FG 全小圖盤）附上。

接上後程式會移除 `Symbol.svelte` 的執行期字母（`lowLetter`）。

## B. 大獎五階（P0）

**目的**：每升一階**物件本身變大、變滿、變吵**，不能只換字。用店內／實驗站實物，不用視窗或面板語言。

| 階 | 物件 | 構圖重點 |
|---|---|---|
| BIG | 單張出餐票卡，夾在出餐鈴旁 | 小、乾淨，紅只在一個戳記 |
| SUPER | 兩張票卡交疊＋鈴＋一根醃漬條 | 開始有斜角動勢 |
| MEGA | 一整罐醃漬罐炸開，票卡從罐裡飛出 | 大面積黑影＋放射墨線 |
| EPIC | 發酵槽爆管，綠色醃汁噴成橫幅 | 橫幅本身就是噴出的液體形狀 |
| MAX | 店長＋女廚師一起舉著大招牌（或從兩側探頭） | 全畫面最滿，兩位角色都在 |

- **規格**：每階 1600×900 透明，中央留**純色字樣區**（米白 #FFF0CF，邊緣 ≥ 6% 留白），字由程式排。
- **分層**（動畫必要）：`*_base`（底板／招牌）、`*_decor`（飛出物、碎片，每件獨立）、`*_burst`（背後放射墨線）。MEGA 以上每個飛出物單獨一張，附軸心座標 JSON。
- **動作規格**（給動畫師／程式對齊）：
  - 進場 0–420ms：從畫面外下方 120% 處甩入，`backOut(1.6)`；落定前 80ms 壓扁 x1.12 / y0.86，再回彈 x0.97 / y1.05，220ms 內收到 1。
  - 飛出物 overlap：比底板晚 60–90ms 出發、各自錯開 40ms，弧線軌跡，落點後小晃 2 次（±4°，衰減 0.5）。
  - 待機循環 2.0s：底板呼吸 ±1.5% 縮放，飛出物各自 ±3° 搖擺、相位錯開；`burst` 慢轉 12°/s。
  - 升階：舊階 160ms 內縮到 0.85 並淡出，新階同上進場；升階當下畫面震 6px／120ms。
  - 退場 360ms：`backIn` 往上甩出，飛出物先走。
- **時長**：跟 `winLevelMap.ts` 現值（big 1.8s／super 3.6s／mega 3.6s／epic 7s／max 9s），音效同步落點。

## C. UI 一整套（P1）

**目的**：bet 列、按鈕、Buy Bonus 招牌要跟圖騰同一枝筆畫出來，不是向量幾何。

| 件 | 現況 | 要 | 尺寸 |
|---|---|---|---|
| Spin 大鈕 | 素紅圓 | 手繪「出餐鈴按鈕」或壓力表旋鈕，墨線不均、偏斜黑影 | 512²，rest／hover／press／disabled 四態 |
| 一般圓鈕底 | `button.png` 素色圓 | 鉚釘鐵皮圓牌，粗墨邊 | 256²，rest／hover（暖色亮起）／press |

| bet 列底條 | `bar_strip.png` 平面條 | 出餐台鐵皮台面，九宮切片可拉長 | 2400×180，標 inset |
| 圖示 11 個 | 平面細線 | 同一枝筆的粗墨圖示（menu／exit／settings／info／paytable／sound on/off／autospin／replay／turbo／±） | 128²，**autospin 與 spin 不能同一張**（現在同 sha） |

## D. 換場門（P1）

**目的**：主→免費遊戲的換場，是全遊戲最常看到的大畫面。

- **物件**：醃漬實驗站的**防爆艙門**，左右兩扇。每扇：厚鐵皮、斜向警示條、一顆圓形觀景窗（看得到裡面晃動的醃汁）、一個手輪閥、一排鉚釘、門中央拼起來是一個大酸黃瓜徽章。
- **分層**：`door_l_base`、`door_r_base`、`wheel_l`、`wheel_r`（軸心在輪心）、`porthole_liquid`（可循環晃動的液面，4 張手繪循環格 或 一張可 UV 位移的液面）、`latch`（門閂）、`steam_01..06`（蒸氣手繪 6 格）、`hazard_bar`（上方警示橫條，取代 `warning_bar.png`）。
- **規格**：每扇 1100×1080 透明（兩扇併起來蓋滿 1920×1080 並各多 140px 重疊），接縫**不要烘雙層陰影**（ART_BRIEF §5）。
- **動作**：
  1. 關門 0–380ms：兩扇從畫外滑入，`cubicIn`；碰撞那一格整畫面震 8px／90ms，門回彈 14px。
  2. 鎖門 380–700ms：門閂橫滑 120ms → 兩個手輪各轉 270°（`backOut`），手輪停下時噴蒸氣 steam_01–06（每格 50ms）。
  3. （遮罩期間換場景、換角色）
  4. 開門：手輪反轉 180°（220ms）→ 停頓 80ms → 兩扇向外 `cubicOut` 460ms，最後 60ms 帶一點過衝。
- 音效同步點：碰撞、手輪、蒸氣、開門各一個 cue（見 S）。

## E. 圖騰分層＋落地／中獎動畫（P1，動畫師主導）

**目的**：每個大圖、Wild、Scatter、罐子都有自己的落地與中獎表演；現在全部共用程式縮放。

**分層交件**（512² 透明，所有層疊回去和現在的單張**逐像素一致**，被遮擋處要補畫）：

| ID | 層 |
|---|---|
| H1 漢堡 | 上麵包／三根酸黃瓜（各自一層）／起司／番茄／下麵包 |
| H2 熱狗 | 麵包下片／香腸（酸黃瓜）／芥末線 |
| H3 炸圈 | 紙籃／三個炸圈各一層 |
| H4 醃漬條 | 三根各一層／墊紙 |
| W 小廚師 | 星爆框／頭／眼鏡／眼睛（開／閉／瞪三格）／嘴（閉／咧／咬三格）／帽 |
| S 出餐鈴 | 鈴身／鈴舌（軸心在頂）／紙票／旗（軸心在桿底） |
| P 醃漬罐 | 罐身／蓋（軸心在左緣）／兩根酸黃瓜／液面 |

**動作規格**（每個都交 Spine 或關鍵影格表）：

- **落地**（240ms，全部共用節奏，強度不同）：0ms 觸地壓扁 → 70ms 回彈 → 160ms 跟隨層（酸黃瓜、旗、紙票）晚 40–60ms 才落定 → 240ms 靜止。Scatter／Wild 強度 1.2–1.25，大圖 1，小圖 0.4。
- **中獎循環**（1.2s 一圈，可重播）：要有預備動作（先往下沉 4%、80ms），主動作，overlap（各層錯開 30–60ms），收尾回到靜態姿勢第 0 格（**最後一格必須等於靜態圖**，否則切回 static 會跳）。
  - H1：上麵包彈起 18%，三根酸黃瓜依序跳起、互相錯開 50ms，起司滴下一滴再縮回。
  - H2：香腸在麵包裡左右滾一圈，芥末線波動。
  - H3：三個炸圈像骰子依序跳、轉 20°。
  - H4：三根像扇子展開再收回。
  - W：眨眼 → 瞪眼 → 咧嘴咬一下，眼鏡跟著頭晚 40ms。
  - S：鈴舌擺 3 下（±22°、衰減），旗子跟著甩，紙票飄起再落。
  - P：蓋子掀開 35°，兩根酸黃瓜探頭，蓋子蓋回時罐身壓扁。
- **Scatter 落地加演**：第 3 顆落地時三顆一起響（鈴舌同步擺），盤面上方出現手繪「DING!」墨字（這個字可以烘進圖，交 3 格手繪）。

## F. FG 背景重畫（P2）

- `ART_BRIEF` §7：FG 是**同一世界失控的發酵實驗**，「另畫場景」。現在 `bg_feature` 與 `bg_base` 構圖、物件、色溫幾乎相同，玩家進 FG 感受不到換場。
- 要：發酵槽破裂、醃汁從管線噴出、警報燈（番茄紅只用在燈罩，不染整張）、地上積液、飛碟換成更近更大的角度。右側角色區仍然是**安靜明亮的冰藍壁面**（brief 規定，這不是空白，是留給角色的）。
- 規格同 MG：1920×1080，另交 1242×2208 直版裁切建議框。
- 動畫層（選配）：`alarm_light`（可旋轉的光錐，硬邊，不要 glow）、`drip_01..04`（醃汁滴落手繪循環）。

## G. Logo（P2）

- 手繪字標「PICKLE PANIC」：字母本身做成醃漬條／罐子變形，粗墨線、偏斜，字距不規則但讀得出。
- 分層：每個字母一層（給進場逐字彈跳）、一個底座（罐子或出餐招牌）、一個 `panic` 的抖動墨線層。
- 規格：1600×600 透明主版；另交 640×240 角落版（右上角用，要在 32px 高時讀得出）。
- 動作：逐字從上落下，每字錯開 45ms，`backOut(2)`，落地壓扁 0.85；全部落定後「PANIC」抖 3 下（±2°、80ms 一下）。待機時每 6s 抖一次。

## S. 音效全套（P0，資深音效設計）

**現況**：`design/generate_pickle_audio.py` 用正弦波依編號變音高生成，SFX 全部 0.65s、贏分全部 1.6s、單聲道 32kHz；有 6 組完全相同的檔案（`win_max`=`win_small`、`fs_intro`=`win_epic`、`reel_stop`=`alarm_bell`=`bill_counter` …）；`sounds.wav` 也只是一串音符；BGM 15–17 秒循環。

**方向**：地下科幻漫畫餐館——老式電子琴／衝浪吉他／舊合成器的 B 級科幻片配樂，加上真實廚房聲（玻璃罐、金屬、鈴、油炸、蒸氣）。

**規格**：48kHz 立體聲、-1 dBTP 上限，BGM 交 m4a（AAC 192k）＋原始 WAV；SFX 交 WAV（遊戲會轉檔）。每個 cue 都要**不同**，同一族用變體（至少 3 個變體避免重複感）。

| 類 | cue（現有名稱） | 要點 |
|---|---|---|
| BGM | `bgm_main` | ≥ 60s 無縫循環，分 3 層 stem（基礎／加打擊／加旋律），程式依盤面狀態疊層 |
| BGM | `bgm_freespin` | ≥ 60s，更快、更緊張；另交 meter 第 2、3 階的加層 stem |
| BGM | 大獎 4 段 | big／super／mega／epic+max 各一段可循環配樂，與 B 的時長對齊 |
| 轉輪 | `spin`、`reel_stop` ×3 變體、`reel_tension`（可循環） | 停輪是金屬托盤落桌，不是音符 |
| 圖騰 | `scatter_1..5` | 出餐鈴，第 1 到第 5 顆音高與層次遞增 |
| 收集 | `sack_land`、`collect_grab`、`coin_in`（可快速連發）、`collect_stamp` | 玻璃罐落盤、開蓋「啵」、收銀 |
| Meter | `tumbler_up`、`dial_tick`、`alarm_bell`、`alarm_trip` | 升階要有明確的「升級感」（上行＋爆裂） |
| 換場 | `door_slide`、`door_clack`、`shutter_slam`、`door_open`、`safe_open`、蒸氣 | 對齊 D 的時間點 |
