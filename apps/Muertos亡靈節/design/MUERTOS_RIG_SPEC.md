# 骷髏樂手：正面吉祥物圖層規格

> 由 `node tools/mascot-rig/mascot.ts brief` 從正面模板（`wp/tools/mascot-rig/template.json`）產生。**Spine 骨架用這個套版骨架做**，不手工綁骨；模板改了就重跑 `brief` 更新這份。造型與換圖頭（`head_blink`、`head_laugh`）見 [MUERTOS_ART_REQUIREMENTS.md](MUERTOS_ART_REQUIREMENTS.md) §8。

正面站姿吉祥物模板：一張畫布、每個部件一張同尺寸透明 PNG（部件留在原位）。L／R 指畫面的左／右（不是角色自己的左右）。

畫布 1024×1536，透明 PNG；每個圖層都是**整張畫布**、部件留在畫好的位置（疊起來就是完整角色）。

參考：`node tools/mascot-rig/mascot.ts mannequin` 會畫出一隻照這份規格的佔位猴子（圖層、關節都在），交件長得像它就對了。

## 圖層（由後往前疊）

| 檔名 | 部件 | 必要 | 被擋住的地方要畫什麼 |
|---|---|---|---|
| `tail.png` | 尾巴 | 選用 | 一整條連續畫完（不要分節）；根部多畫進骨盆後面 |
| `ear_l.png` | 畫面左・耳朵 | 選用 | 耳根多畫進頭的後面（會被頭蓋住） |
| `ear_r.png` | 畫面右・耳朵 | 選用 | 耳根多畫進頭的後面（會被頭蓋住） |
| `leg_l.png` | 畫面左・整條腿（含腳掌） | ✓ | 大腿到腳掌一整條，膝蓋不要畫圓頭；大腿上端多畫 40px 藏進短褲；膝蓋往外微彎 15–20° |
| `leg_r.png` | 畫面右・整條腿（含腳掌） | ✓ | 同左腿 |
| `pelvis.png` | 骨盆／短褲 | ✓ | 上緣多畫藏進軀幹下面，兩個腿洞（大腿根）要畫滿 |
| `neck.png` | 脖子 | 選用 | 上端伸進頭裡，下端藏進衣領（軀幹）後面 |
| `torso.png` | 軀幹（胸、腹） | ✓ | 兩肩、腋下、被手臂擋住的胸側全部畫完（舉手時會露出來） |
| `arm_l.png` | 畫面左・整條手臂（含手） | ✓ | 肩到手一整條：肩膀頂端畫成以肩關節為圓心的圓（半徑＝手臂半寬），手肘不要畫圓頭；手肘微彎 10–20° |
| `arm_r.png` | 畫面右・整條手臂（含手） | ✓ | 同左手 |
| `head.png` | 頭（臉） | ✓ | 下巴下面多畫一點蓋住脖子上端 |

疊圖順序不同（例如某隻手畫在臉前面）時，附 `layers.json`：`{ "order": ["tail", …, "head"] }`。

## 比例（從動作反推，畫之前先確認）

- 肩關節到手腕的長度（上臂＋前臂）至少要等於肩關節到頭頂的高度，舉手才舉得過頭（少於 1.0 會蓋在頭上）
- 手肘畫成微彎 10–20°（太直的手臂一呼吸 IK 就會啪一下）
- 膝蓋往外微彎約 15–20°、兩腳打開與骨盆同寬，腳掌平貼地面（腿畫直的話，骨盆一傾斜腳就會離地）

## 為什麼

- 手腳尾巴要一整條：骨架用加權網格在關節處彎曲，分節畫會在關節露出切口。
- 肩膀頂端是圓：手臂繞肩關節轉（舉手到 130°），圓心對準關節才不會露縫。
- 被擋住的地方要畫完：舉手、蹲下時會露出來。
