# Jade Teahouse cover layers

- `JadeTeahouse-Cover-BG.png`: 1920×1080 opaque tea room.
- `JadeTeahouse-Cover-FG.png`: 1920×1080 transparent Master and Apprentice layer aligned to the background.
- `JadeTeahouse-Master-Cutout.png` and `JadeTeahouse-Apprentice-Cutout.png`: separate transparent full-body figures.

Regenerate from the game art with `python design/build_jade_cover.py` from the app directory. The older `SushiMonkey-Cover-*` files belong to the source game.
