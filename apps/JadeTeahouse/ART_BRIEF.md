# Jade Teahouse（玉茗茶樓）美術方向

以 Sushi Monkey 前端的互動與骨架為基礎，換成明亮中式茶樓。畫法延續原作的漫畫墨線、交叉排線、稀疏網點及平面色塊；色彩以象牙白、青瓷綠、淡玉色、暖金為主，保留清晰的獎值及按鈕對比。

| 原元素 | 新元素 |
|---|---|
| 深夜壽司店 | 日光茶樓、木格窗、山水遠景、茶席 |
| 壽司師傅 | 穿中式茶服的老茶師與年輕學徒 |
| 壽司盤 P | 玉杯 P |
| 點單鈴 S | 節慶燈籠 S |
| 壽司獎圖 H1–H4 | 玉茶壺、蓋碗、竹蒸籠、茶盤 |
| 壽司吧台外框 | 青瓷雕花、金線盤面框 |
| 復古收據與電腦視窗 | 米白紙、木牌、青瓷與金邊 UI |

角色沿用原有動作骨架與命中範圍，重新切圖並產生 Spine atlas。美術來源在 `design/source/jade/`；由 `design/build_jade_art.py` 輸出遊戲資產。完整生圖提示見 `design/IMAGEGEN_PROMPTS.md`。

目前語音／配樂仍沿用原遊戲音檔，正式發行前應製作對應茶樓氛圍的音效與音樂。角色表情使用新頭部的同一張 neutral 圖作各表情暫代，動作正常但表情沒有切換。
