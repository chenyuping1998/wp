# Hard Time — 得獎級素材需求單（2026-10-12）

來源：2026-10-12 三款體檢（報告 https://claude.ai/artifact/XSrbqABbX1VmV5LVv7y6W4）。
程式能修的已經修完（`docs/handoff/trilogy-polish-20261012.md`，其中低賠花色已從格子的 25–31% 放大到約 66%）；
這份只列**要新素材**才能補的差距，依對審核星數的影響排序。**數學一律不動**（三檔規則、探照燈頻率都不動）。

保留色規則照 `ART_AUDIO_BRIEF.md` §0：**探照燈的冷白青光（光芯 `#DCE8F0`、光暈 `#8FB4C8`）是全款唯一的訊號色**，
其他地方一律走水泥灰、鏽鐵、卡其囚服的暖濁色。交件放 `design/_incoming/award_20261012/<區塊>/`。

## A. 聲音（影響最大）

| | 現在 | 目標 |
|---|---|---|
| 來源 | numpy 合成（`design/generate_hard_time_audio.py`） | 實際錄音／製作級音樂庫 |
| 音效數 | 42 個 | ≥ 90 個 |
| 配樂 | 2 首，循環 32／30 秒（已轉 m4a） | 4 首（主遊戲、Lockdown、Riot、Breakout），2–3 分鐘、4 層強度 |

### A.1 配樂（監獄藍調／工業）

| 曲 | 速度 | 四層 |
|---|---|---|
| 主遊戲 | 84 bpm 慢藍調，E 小調 | L0 原聲吉他滑音＋低音／L1 ＋鐵器打擊（湯匙敲鐵欄、腳鐐）／L2 ＋口琴旋律／L3 ＋電吉他與鼓（預中、大獎前） |
| Lockdown | 96 bpm，停電的牢房 | L0 嗡鳴＋滴水節奏／L1 ＋打擊／L2 ＋口琴／L3 ＋警報合成器 |
| Riot | 128 bpm 工業搖滾 | L0 鐵器節奏／L1 ＋電吉他 riff／L2 ＋群眾吶喊取樣／L3 ＋全團 |
| Breakout | 140 bpm 追逐 | L0 心跳低音／L1 ＋直升機葉片節奏／L2 ＋弦樂／L3 ＋銅管與定音鼓 |

規格：48 kHz 立體聲，四層等長、樣本級無縫循環，交 WAV（我轉 m4a）。

### A.2 音效清單（括號內 = 變化數）

**轉輪**：spin_start(2)、reel_stop_1–5(各 2，鐵門扣上的金屬聲)、reel_stop_tease(2)、anticipation_riser（警報漸起＋心跳，可循環）、anticipation_hit。

**符號落地**：花色牌 card_flick(4)；高賠 —— 鑰匙串 keys_jingle(3)、手銬 cuffs_snap(2)、鐵盒 box_thud(2)、鐵杯 mug_clank(2)、
刻痕布 chalk_scratch(2)；Wild 囚帽 cap_slap(2)；Scatter 牢門 cell_door_1–5（越多顆越重、最後一顆加門閂）。

**探照燈（本作唯一的機制）**：
- lamp_power_on（電弧嗡一聲）→ beam_sweep_1–4（光往下照 1–4 格，長度對應）→ cell_lit(3)（照到時「叮」的冷光聲）。
- beam_overlap_double（兩道光交叉：電流加倍的上揚音＋短促警報）、beam_carry（免費遊戲裡光留著的低嗡，可循環）、
  multiplier_stamp(3)（倍數蓋章）。
- 觸發：siren_full（監獄警報）、gate_slam（鐵門關上）、gate_open、tier_lockdown／riot／breakout（三支開場短句）、retrigger_sting(2)、fs_outro。

**贏分**：win_line_tick(3)、win_count_loop、win_end_low／over／high、big_win_big／super／mega／epic／max（逐級加口琴與電吉他）、
coin_shower_loop（硬幣落在鐵板上）、bigwin_impact。

**介面**：ui_click(3)、ui_hover、bet_up、bet_down、bet_max、menu_open/close、buy_menu_open、buy_confirm、autoplay_start、turbo_toggle。

**環境**：cellblock_ambience（遠處咳嗽、鐵門、日光燈嗡嗡，60 秒循環）、yard_wind（Breakout 用）、mess_hall（Riot 用）。

**人物短句**：
- 囚犯：「Doing time.」低笑(2)、嘆氣(1，連續 10 手沒中時偶爾)、「Freedom!」（大獎）
- 典獄長：「Lights out.」（進免費遊戲）、哨音(2)、「Back in line.」（結算）

規格：44.1 kHz／16-bit WAV，峰值 −1 dBTP，短音效前端不留靜音。授權須涵蓋真錢博弈遊戲商用。

## B. 符號動畫

每個符號交落地 0.5 秒與中獎 1.0 秒，24 fps 序列圖（512×512／格，洋紅底）或分件圖＋樞紐點。

| 符號 | 落地 | 中獎 |
|---|---|---|
| H1 鑰匙串 | 落下鑰匙晃 | 鑰匙串甩一圈、一把鑰匙反光 |
| H2 手銬 | 喀一聲 | 手銬開合一次、鍊子晃 |
| H3 鐵盒 | 重落 | 蓋子掀開一條縫、透出光（冷光以外的暖光） |
| H4 鐵杯湯匙 | 湯匙晃 | 湯匙敲杯緣兩下 |
| H5 刻痕布 | 落下 | 多刻一道痕（序列 6 格） |
| W 囚帽 | 落下 | 帽子轉半圈、W 字閃 |
| SW 探照燈 | 燈頭轉向盤面 | 燈頭亮起（接 C.1） |
| S 牢門 | 鐵欄晃 | 門閂拉開、門開一條縫 |
| L1–L4 花色 | 落下 | 花色像刻在肥皂或木牌上的「監獄自製撲克」，中獎時刻痕發光一次 |

**低賠建議重畫**：現在是平塗小花色（已用程式放大到格子約 66%）。得獎級做法是畫成監獄自製撲克 ——
花色刻在木牌、肥皂或厚紙牌上，有實體厚度與磨損，跟高賠的寫實物件同一個世界。提示詞：
```
"Prison-made playing card suit SPADE carved into a worn bar of soap, chipped edges, tally scratches,
warm grimy beige and rust tones, photoreal object, centred, fills 70% of the frame,
magenta #FF00FF background, no text"
```
（四張同一塊材質；花色輪流 spade／heart／diamond／club；紅心與方塊用暗鏽紅，不准用探照燈的冷青光。）

## C. 招牌鏡頭

### C.1 探照燈（現在看起來是 UI 方框）
現況：被照到的格子是藍色半透明方框加「1x／2x」小字。
目標：
1. 燈頭落定後轉向下方、電弧一閃（0.2 秒）；
2. 一道有體積感的冷光錐從燈頭往下掃到底（每格 0.12 秒），光錐裡有灰塵粒子；
3. 被照到的符號**本身變亮**（不是蓋方框），邊緣一圈冷光；
4. 倍數用**鋼印牌**蓋在格子右下角（「×5」字由我排，這裡要空白鋼印牌）；
5. 兩道光重疊加倍：兩道光錐交叉處閃白、鋼印牌換成雙倍版（加紅色鋼印邊）。
需要的圖：光錐（可縱向拉伸、頂端窄底端寬的半透明單件，透明底）、灰塵粒子 6 種、鋼印牌空白版與加倍版、燈頭電弧序列 4 格。

### C.2 觸發免費遊戲
現況：轉場是黑畫面＋紅色警示角。
目標：警報燈旋轉（紅光掃過整個畫面）→ 牢門鐵欄從左右關上 → 典獄長的手電筒光掃過 → 開門進免費遊戲。
需要：牢門鐵欄左右兩扇（全螢幕、透明底）、警報燈旋轉光斑。

## D. 人物表演

囚犯目前只切了**頭與身體兩層**（雙手交叉黏在身體上），只能點頭與整體晃動，反應幾乎看不出來。

| 時機 | 囚犯（主遊戲） | 典獄長（免費遊戲） |
|---|---|---|
| 待機（每 6–10 秒） | 毛巾換肩、抬頭看探照燈 | 警棍拍手心、看錶 |
| 預中 | 鬆開手臂、身體前傾 | 吹哨 |
| 探照燈出現 | 抬手遮眼 | 用警棍指向光 |
| 一般中獎 | 嘴角上揚 | 皺眉 |
| 大獎 | 雙拳握緊舉起 | 慌張後退 |
| 進免費遊戲 | 被典獄長推開（開場卡上） | 登場站定 |
| 連續 10 手沒中 | 搖頭、靠牆 | — |

需要：**囚犯重切分層**（頭、軀幹、左右上臂、左右前臂、毛巾，照 `design/cast_brief/` 規則，手臂離開身體至少 24 px）；
表情 3 種、眨眼 3 格；典獄長表情 2 種、哨子手勢。
