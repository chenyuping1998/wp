# Stream Time（Break Studios）— 畫風與動態抄錄

> 用途：之後換皮要做「漫畫實況房間」這一類風格時，照這份重現畫風、場景生命感、
> 角色待機與停輪節奏。只抄手藝（時序、比例、構圖、做法），不抄美術本身。
> 證據（影片、逐格表、動圖、量測原始輸出、工具）放在 repo 外：
> `/Users/stone/stake-engine/research/stream-time/`（wp 是公開 repo，截圖不進 git）。

- 遊戲：《Stream Time》，Break Studios，Stake 獨家，說明頁版本 0.1.0，「TM and © 2026 Engine」
  （Stake Engine 第三方工作室作品，跟我們同一個平台）。
- 素材：使用者 2026-10-15 錄的 39 秒螢幕錄影（1280×688、24 fps、有音軌）＋ 一張開場畫面截圖。
  遊戲畫布在錄影裡是 (137,137)–(937,587)，即 **800×450（16:9）**；下文所有像素數字都是這個尺度，
  另附「佔畫布高 %」方便換算。
- 錄影內容：0–17.7 秒待機 → 17.75 秒按一手（沒中獎）→ 21–25 秒待機 → 26–37 秒翻說明頁 → 回遊戲。
  **只有一手**，沒有中獎演出、沒有免費遊戲、沒有加購 —— 見 §8 缺口。

## 1. 題材與世界觀

- 場景是一間實況主的臥室直播間「DEGEN CAVE」：吸音棉、螢幕、懸臂麥克風、網路攝影機、
  桌上一盒面紙（笑點）、霓虹招牌、紅色 LIVE 燈、右邊一扇門、木地板。整個題材在消遣博弈直播圈。
- 道具全部是直播桌上的東西：能量飲料「DEGEN FUEL」、金錶、筆電、麥克風、電競滑鼠。
- 模式名稱用直播圈黑話：Stream Time（免費遊戲）、Influencer、Insane、Hidden、Unhinged Spin、Split Spin。
- 左上角常駐「STREAM TIME | 13:49」——**時間是真實時鐘**（錄到 13:49 → 13:50），
  做得像直播疊加層（overlay）；盤面上方「144 WAYS」即時顯示目前路數。
- **世界觀物件兼任介面**：霓虹招牌就是模式指示燈（§5.3），盤面底部的「抽屜」就是金框計數器。

## 3. 畫風

### 3.1 媒材
- 西方獨立漫畫／圖像小說風：**粗黑筆刷墨線**（800 寬時約 2–4 px，有粗細變化）、
  2–3 階平塗陰影 ＋ 排線、整張帶細顆粒與印刷斑駁感。不是光滑 3D 渲染。
- 人物是「醜得很具體」的漫畫寫實：鬍渣、半睜死魚眼、啤酒肚、汗感。
  最接近我們目錄的 **American comic** 再混一點 Nolimit City 的 **caricature**。
- 開場卡片上的人物用同一套筆法，但打光比較完整、上色比較飽和（宣傳圖等級）。

### 3.2 色彩（idle 畫面量測，`stills/palette_ingame.png`）
- 整個世界是**單一藍紫色調的夜晚**：有彩度像素裡 83% 落在藍色色相（背景 88%、盤面 85%）。
- 亮度分層：房間背景平均亮度 0.18 → 盤面紙卡 0.36 → 人物 0.36（p90 0.60）。
  **盤面比房間亮一倍**，所以不用輪框也跳得出來。
- 暖色只留給：人物膚色、金錶／皇冠的金、能量飲料的酸綠、LIVE 燈的紅。
  亦即「冷色世界 ＋ 少量暖色重點」，重點色都長在角色和高價道具上。
- 12 色主色（佔比）：#6b718e 17% · #22252e 16% · #363741 15% · #535e88 12% · #474a5a 10% ·
  #04050a 9% · #15191f 9% · #716152 4% · #baa583 4% · #8294b6 3% · #e5e2d6 2% · #063f65 0.3%。
- 霓虹招牌字青色（約 #5ad0f0），會在待機時掃過綠、黃（§4.4）。

  - Wonder Bro：橘髮圓臉胖子、握麥克風、灰 T 恤。
  - Pinkyz：戴漁夫帽、戴拳擊手套的袋鼠（開場卡「Unhinged Spins」）。

## 4. 待機動態（場景的生命感）

動態熱度圖：`stills/motion_heatmap_idle_0-17s.jpg`。待機時會動的只有：胖實況主、角色圖騰、
左下老鼠、招牌。其他（道具圖騰、背景物件、介面）完全靜止。

### 4.1 全域 2 秒時鐘
- 胖實況主、所有角色圖騰的待機循環**都是 2.00 秒，而且同相位**（三隻 Shipwreks 完全同步，
  2.1／4.1／6.1 秒同時回到起始姿勢）。整個盤面像一起呼吸。
- 量法：`tools/period.py`、`tools/phase.py`；原始輸出 `measurements/idle_periods.txt`。

### 4.2 右側胖實況主（`gifs/02_man_idle_2cycles.gif`、`sheets/p_head.jpg`）
- 主要動作是**頭部慵懶點頭**：上下幅度 8.8 px（畫布高 2.0%），週期 2.0 秒。
- 曲線（`measurements/man_head_curve_0-4s.txt`）：
  0.4 秒快速垂下 → 停 0.6 秒 → 0.8 秒慢慢抬起並略超過原位（約 −3 px）→ 0.25 秒回正。
  是「放空、快睡著」的節奏，不是對稱的正弦呼吸。
- 頭髮尖端有甩動延遲（1.5→1.88 秒髮尖翻起）。眼睛始終半睜翻白。
- 肩膀只動 1–2.6 px，肚子、手幾乎不動（< 0.2 px）。**幅度全集中在頭**，身體當穩定的底座。

### 4.3 角色圖騰（`gifs/04_symbol_idle_sync.gif`、`sheets/p_ape.jpg` / `p_snake.jpg` / `p_kill.jpg`）
- 整體位移只有約 1 px（格高 1%），但臉部內部變化大（像素差 11–20）：
  是網格變形／逐格的表情待機，不是整張圖在晃。
- Shipwreks：頭和皇冠微擺、摸下巴的手在動、拿罐子的手微移。
- Snake Oil Salesman：鈔票抖動、頭微傾。
- KillClad：眼珠往上飄、頭微傾、杯子微抬。
- 道具圖騰（罐子、錶、筆電、麥克風、滑鼠、Scatter）待機時不動。

### 4.4 霓虹招牌（`gifs/03_sign_flicker.gif`、`sheets/p_sign.jpg`）
- **每 6.0 秒**（1.79、7.79、13.79、19.79 秒）上排「DEGEN」做一次 0.35 秒色掃：青 → 綠 → 黃 → 青。
  下排「CAVE」不變。
- 綠＝免費遊戲、黃＝Influencer 的模式色（§5.3）——待機閃爍等於在偷偷預告模式顏色。

### 4.5 老鼠（`gifs/01_rat_loop.gif`、`sheets/p_rat1.jpg` / `p_rat2.jpg`、`measurements/rat_track_0-17s.txt`）

| 17.9 – 20.1 | 全速：每格 50 px（24 fps）≈ **1200 px/s ≈ 每秒 11 格**；**沒有動態模糊**，圖騰在每一格都清楚 |
| 20.15 | 第 1 輪停 |
| 20.27 | 第 2 輪停 |
| 20.36 | 第 3 輪停 |
| 20.44 | 第 4 輪停 |
| 20.52 | 第 5 輪停 |
| 20.25 / 20.42 / 20.54 | **震屏三下**（見 5.2） |

- 按下到第一輪停 2.4 秒；按下到全部停 2.8 秒；按下到完全靜止約 2.9 秒。
- **停輪間隔約 0.09 秒**（0.12、0.09、0.08、0.08）。Hacksaw 常模一般速度 0.2 秒、加速 0.1 秒
  （`hacksaw-style-transcripts.md`），這款比 Hacksaw 加速模式還緊 —— 五輪像「一口氣砸下來」。
- 每輪停：最後一格減速（約 25–35 px/格），落定後回彈 4–5 px（畫布高約 1%）。
- 金框是**黏在圖騰上一起轉下來的**（20.29 秒第 3 輪頂端的框還在移動中），不是落定後才長出來。

### 5.2 震屏（「很震撼」的來源）
- 只震**場景層**：背景、盤面、人物一起動；**底部按鈕列和左上標題不動**。
- 只有垂直、向下一頓：第 1 格 4.8 px（畫布高 1.07%）→ 第 2 格 1.6 px → 第 3 格歸零，約 0.1 秒。
  三下幅度 4.8 / 3.1 / 4.7 px。
- 聲音：20.13–20.73 秒是一串密集打擊聲 —— 五下停輪聲（20.13 / 20.27 / 20.35 / 20.43 / 20.50，
  和畫面量到的停點吻合），中間夾較重的悶響，20.62 一下分裂聲。
- **哪一種落地才震，這支影片還判定不了。** 五輪停、只有三下震，兩種讀法都說得通：
  (a) 震在第 2、4、5 輪落定的同一格；(b) 震在第 1、3、5 輪落定後 1–2 格（第 1、3、5 輪是
  Scatter 相機會出現的輪）。這一手的金框落在第 3、5 輪。
  使用者觀察到「停輪節奏會因為不同圖騰不一樣、有時候很震撼」——要把規則釘死，
  需要再錄 10–20 手（最好包含 Scatter 相機、綠幕、金框、神秘角色、有中獎的），用 §9 的工具量。

### 5.3 金框分裂與模式提示
- 分裂是**一格硬切**：原本一格的角色，下一格變成上下兩個半高的同角色，兩片各自帶金框。
  沒有過場動畫，靠同一格的音效、路數跳動、抽屜數字一起變來給感覺。
- 模式顏色由**世界物件**表達（說明頁原文的整理）：
  - 一般遊戲：青色招牌，外框不發光。
  - Stream Time 免費遊戲：綠色招牌 ＋ 綠色外框循環光。
  - Influencer：黃色招牌 ＋ 黃色暗角 ＋ 黃色外框光。
  - Insane：紅色招牌 ＋ 紅色暗角 ＋ 紅色外框光。
  - Hidden：專屬的 Hidden 招牌 ＋ 紅色外框光。
  - 換模式時，有一張動畫遮罩從招牌前面掃過、招牌趁機換字換色；外框光跟著換。
  - 一般遊戲中獎時外框短暫閃綠。MAX 角色有循環的金色流光。

## 6. 玩法摘要（說明頁）

- 5 輪，起始格數 3-2-3-2-3（108 路），從左算連續 3 輪以上同圖就贏；沒有消除連鎖，每一盤只算一次。
- **金框**：把圖騰切成兩片；免費遊戲中留在原位。
- **Triple Reveal**：三格面板翻開成三個同圖並把該格加高。
- **Symbol Cuts**：切割圖騰把指定格切成更多片，然後自己變成兩個百搭。
- **Reel Boost**：箭頭長成加高的百搭，帶倍數，加乘所參與的路。
- **神秘角色**：兩個以上會揭曉底下是誰，各帶一個數字或 MAX，可把值給另一個同名角色。
- **角色數字**：代表這個角色算幾個同圖；MAX 角色本身必須在中獎路上才給到最高倍數。
- **角色銀行**：角色圈把數字存起來給之後的手用，小徽章是還能給幾次。
- **底部抽屜（Bottom Enhancers）**：數全盤金框格數；4 個開第 2 輪下方的加成、6 個開第 4 輪下方的加成；
  一般遊戲每一手重新計算。
- **免費遊戲**：第 1、3、5 輪的 Scatter 相機觸發 8 次 Stream Time，每個被金框框住的原始 Scatter ＋1（3 框＝11 次）。
  第 2、4 輪的綠幕：一個 → 改成 9 次 Influencer；兩個 → 10 次 Insane。遊戲中綠幕可升級模式、加次數。
  綠幕是揭曉圖騰，翻出角色、百搭、神秘角色、Triple Reveal 或切割圖騰。
- **Hidden**：13 個金框全滿、兩個加成都開、兩個綠幕常駐，角色數字從 25 起跳。

## 7. 換皮重現清單

給之後的換皮直接抄的設定（數字以 800×450 畫布、24 fps 量得；實作時用「佔畫布高 %」換算）：

| 項目 | 數值 |
|---|---|
| 全域待機時鐘 | 2.0 s，所有角色、角色圖騰同相位起跑 |
| 場景角色點頭 | 幅度 2.0% 畫布高；曲線 0.4 s 垂下／0.6 s 停／0.8 s 抬起超出 0.7%／0.25 s 回正；頭髮延遲甩動 |
| 角色圖騰待機 | 整體位移 ≤ 1% 格高，表情（眼、眉、手、道具）自己動 |
| 道具圖騰 | 待機不動 |
| 小動物路徑循環 | 16 s 左右一輪：窩 3.5 → 出門 4.3 → 停 2.2 → 站起 0.3 → 嗅 2.0 → 趴 0.3 → 轉身 0.7 → 回家 3.0；窩藏在介面下 |
| 招牌色掃 | 每 6.0 s 一次、0.35 s，掃過下一個模式的顏色 |
| 起跑 | 五輪同一格起跑，0.1 s 到全速，不蓄力 |
| 轉速 | 每秒約 11 格，不加動態模糊 |
| 第一輪停 | 按下後約 2.4 s |
| 停輪間隔 | 0.09 s（一般速度） |
| 回彈 | 約 1% 畫布高 |
| 震屏 | 只震場景層、不震介面；向下 1.07% → 0.36% → 0，約 0.1 s；重的落地才震 |
| 金框 | 黏在圖騰上一起轉；分裂一格硬切 ＋ 路數、計數同格跳 |

做法上要帶走的決定：
1. **盤面不加框**，紙卡格浮在房間裡；盤面亮度約房間兩倍。
2. **冷色單一色調世界 ＋ 暖色只給角色和高價道具**。
3. **介面物件放進世界**：招牌＝模式燈、抽屜＝計數器、左上＝直播疊加層（真時間）。
4. **一隻跟玩法無關的小動物**長循環地在房間裡活動、會被介面擋住一半 —— 生命感的成本很低。
5. 所有待機共用一個時鐘，盤面看起來在一起呼吸；場景角色的幅度集中在頭部。
6. 停輪要「短促、密集、重的才震」，震屏不碰介面。
7. 標題字：上下硬切兩色 ＋ 速度刮痕 ＋ 厚黑陰影 ＋ 細亮外框；開場卡角色衝出框。

跟我們現有規則的關係：
- 人物只在側邊、不壓盤面（cast-never-overlaps-board）：這款的實況主貼著第 5 輪外緣，符合。
- 人物要從背景跳出來（cast-reads-off-background）：這款靠暖膚色 ＋ 比房間亮一倍，而不是在背後墊淺色板。
- 我們的起跑錯開（25 ms）和停輪間隔（約 0.2 s）都比這款慢；要做這種手感就照 §5.1 改，
  改已上線遊戲前先跟使用者確認。
- 場景角色的動作庫用 `hacksaw-character-motion`；這款的「坐著點頭放空」可以做成新的待機動作表。
