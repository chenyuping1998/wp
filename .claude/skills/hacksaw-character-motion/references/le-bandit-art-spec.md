# 要做出 Le Bandit 這種動態，圖要怎麼生

前置：[`le-bandit-motion.md`](le-bandit-motion.md) 是動態本身的拆解，
這份是**反推回去的美術規格** —— 你要生一隻自己的角色、套上一樣的動作，需要準備什麼。

> **要完全照浣熊的動作複製到你的角色上，照 [`motion-library.md`](motion-library.md) 的浣熊那節做**
> （`python spineplay/motionlib.py -c 6 --guide --out 零件指引/`）—— 那邊的零件清單、每個零件的
> 輪廓範本、`--checkart` 檢查都是從骨架實測、而且驗證過的。這份是早期從骨架反推的設計筆記，
> 當背景知識讀；兩邊說法不一樣時以動作庫為準。

---

## 0. 先講最重要的一件事

**這種動態需要「切好的零件」，不是一張完整的圖。**

Le Bandit 的頂點綁定統計：

| | 頂點綁到 2 根以上骨的比例 |
|---|--:|
| Miami Mayhem `character_main_guy` | **86%** |
| **Le Bandit `raccoon`** | **21%** |

而且 21% 集中在四個部位（尾巴 63%、身體 51%、生氣臉 45%、伸長手 43%），
**其餘全部是 0%** —— 手、帽子、嘴、眼睛、瞳孔、鞋、鬍子、撬棍，
每一片都是硬綁在單一骨上的剛性圖層。

這跟我們 `rig/` 那套的前提**正好相反**。`rig/` 存在的理由是
「一張平面圖不切開，所以永遠不會有接縫」；
Le Bandit 的整套語彙 —— 換手臂圖層、鬍子飛出去、鏡像翻轉、180 度甩動 ——
**只有切開才做得到**。

> **所以：想要 Le Bandit 的演出，就不要用 `rig/`。**
> `rig/` 適合的是「一張生成圖，我要它活起來但不能有破綻」；
> 這裡要的是「我有一套零件，我要它演戲」。兩件事。

## 1. 畫布與比例

```
骨架框   998 × 1372
地面     y = −496（root 的位置）
頭       y = +165        帽子 y = +403        耳朵 y = +387 / +394
膝蓋     y = −230 / −254
鞋       y = −396
圖的上緣 y = +859（帽子與撬棍伸出去的部分）
```

換算成身高比例（地面到頭頂約 1000 單位）：

| 部位 | 佔身高 |
|---|--:|
| 地面 → 膝蓋 | **26%** |
| 膝蓋 → 髖 | 3% |
| 髖 → 胸 | 15% |
| 胸 → 頭 | 24% |
| 頭 → 帽頂 | **24%** |

**腿極短、頭極大。** 頭部圖（564×456）是身體圖（726×675）的 78% 寬。
這是吉祥物比例，不是人體比例 —— 而且它是**必要的**，
因為這套動畫的情緒全靠頭、耳朵、鬍子演，頭小了就讀不到。

### 朝向

鼻子在 x = −303、頭在 −189、尾巴在 +88。
**四分之三側面，面向畫面左邊。** 不是正面，也不是全側面。

## 2. 姿勢：兩隻手要不對稱，而且要「有事在做」

setup pose 的世界座標：

```
L_sholder ( +14, +134) → L_elbow (+149, +217) → L_hand (+231,  +93)
R_sholder (−236,  +54) → R_elbow (−380,  +12) → R_hand (−345, −118)
```

- **左臂（遠側）往前上方抬起再折下來** —— 肘比肩高 83 單位，手又落下 124。
- **右臂（近側）往後下方垂** —— 肘比肩低 42，手再低 130。
- 左手握著撬棍（`Crowbar` 514×500，是全身第五大的圖）。

**兩隻手的角色完全不同**：一隻拿東西、一隻空著。
這不是美觀問題，是**動畫需求** —— 21 段動畫裡，
拿東西那隻負責道具演出，空的那隻負責摸臉、丟帽子、打招呼。

> **生圖時最容易錯的一點**：讓角色雙手對稱下垂或雙手插腰。
> 那樣就沒有「空的那隻手」可以演戲，一半的動畫做不出來。

## 3. 圖層清單：最少要切成這些

按 Le Bandit 的實際切法整理，標出哪些是**非切不可**、哪些可選：

### 必要（沒有就做不出對應動畫）

| 圖層 | 參考尺寸 | 為什麼必須分開 |
|---|--:|---|
| **身體** | 726×675 | 唯一的核心，其他都掛在它上面 |
| **頭（預設表情）** | 564×456 | 頭要能獨立轉、獨立位移 |
| **左臂**、**右臂** | 346×241 / 230×224 | 兩隻手要能各自轉 ±40° |
| **左手**、**右手** | 各約 200×250 | 手腕要能獨立轉 |
| **尾巴** | 489×656 | 全身變形最大的部位（63% 多重綁定）|
| **耳朵 ×2** | — | idle 就在轉 ±13~15°，是生命感主力 |
| **帽子** | 329×187 | 會被丟、被踩 |
| **鬍子** | — | 會整個飛出去（`lost_mustache`）|
| **眼睛**、**瞳孔** | 284×162 / — | 瞳孔要能單獨移動追東西 |
| **鞋** | 282×194 | 跺腳 |

### 表情替換（同一個位置的備用圖）

| 圖層 | 用在 |
|---|---|
| 生氣臉 567×470 | 輸的時候 |
| 驚訝臉 567×417 | 中獎的瞬間 |
| 嘴 ×3（開心 / 哼 / 壞笑）565×316 等 | 三種情緒 |

**臉是整張換，不是拼五官。** 三張臉尺寸接近、對齊同一個錨點，
用一幀（0.03 秒）硬切。這比做一套可動五官省得多，而且表情可以畫得更誇張。

### 手臂替身（做特定演出用）

| 圖層 | 用在 |
|---|---|
| 伸長的手臂 127×427 | 伸手去拿 / 指 |
| 前臂 ＋ 摸臉的手 | 摸臉、抓頭 |
| 打招呼的手 212×248 | `welcome` |

**同一隻手臂準備 2–3 種姿勢的圖**，切換靠一幀硬切。
這是這套動畫看起來「動作很多」的真正原因 ——
不是骨骼擺得多好，是**準備了好幾套零件**。

## 4. 每一片要畫到哪裡（遮擋）

因為是切件，被擋住的部分**必須畫完整**，否則一轉就露餡：

| 片 | 要畫到 |
|---|---|
| 身體 | **肩膀、髖部畫完整**，包含手臂與尾巴蓋住的部分 |
| 手臂 | **畫到肩窩裡面**，留出轉 ±40° 不會露出接縫的重疊量 |
| 頭 | 下巴與後腦畫完整（頭會轉、會位移 40px）|
| 尾巴 | 根部塞進身體裡 |
| 帽子 | **整頂畫完**（會被丟出去，那時全部可見）|
| 鬍子 | **整撮畫完**（會飛出去）|

### 為什麼它敢轉 ±40° 而不破

三個原因，缺一不可：

1. **粗黑描邊。** 每一片都有明顯的外框線，接縫藏在線裡。
2. **重疊量大。** 手臂根部深深插進身體。
3. **關節處是圓的。** 肩、肘、腕都畫成圓弧，轉起來輪廓不變。

**這三點是畫風選擇，不是後製能補的。**
寫實質感或細線條的角色切開來轉 40 度一定看得出來。

## 5. 生圖要怎麼下提詞

按上面的規格，給圖像模型的方向大致是：

> **主體**：一隻〈你的角色〉的全身吉祥物插畫，四分之三側面、面向畫面左方，
> 站姿。**大頭短腿**的卡通比例（頭約佔全身 1/4，腿約 1/4）。
> **粗黑描邊**、平塗上色、關節處輪廓呈圓弧。
>
> **姿勢**：**兩手不對稱** —— 一手抬起在胸前握著〈道具〉，
> 另一手自然垂在身側且**空著**。雙腳分開站穩，重心略偏一側。
>
> **一定要有的部位**：造型明顯的頭部配件（帽子之類，可以被丟掉的）、
> 一條會甩的附屬物（尾巴／辮子／圍巾）、明顯的耳朵或等效的可動突出物、
> 一撮可以掉下來的臉部特徵（鬍子／眉毛）。
>
> **背景透明，單一角色，不要陰影投射在地面上。**

然後**另外單獨生**（同一畫風、同一角度）：

- 生氣的臉、驚訝的臉（跟主圖的臉同尺寸同位置）
- 三種嘴型
- 抬起打招呼的手、摸臉的手、伸長的手臂
- 帽子單獨一張（完整、不被頭遮）

### 四個常見的失敗

| 症狀 | 原因 |
|---|---|
| 切開一轉就有縫 | 描邊太細或沒有描邊；關節畫成方角 |
| 一半的動畫做不出來 | 兩手對稱／雙手都握著東西，沒有空的手 |
| 情緒讀不到 | 頭太小。這套動畫的情緒 80% 在頭上 |
| 沒有生命感 | 沒有會甩的附屬物。idle 的主力是耳朵 ±15° 與尾巴 ±9° |

## 6. 兩條路，選一條

| | **切件路線**（Le Bandit）| **連續網格路線**（我們的 `rig/`）|
|---|---|---|
| 圖 | 10–20 張切好的零件 ＋ 替換表情 | **一張完整的圖** |
| 能做 | 換圖層、鏡像、大角度、零件飛出去 | 呼吸、搖晃、小幅反應 |
| 不能做 | —（幾乎什麼都能）| 任何需要「露出被遮住部分」的動作 |
| 接縫風險 | **高**，靠畫風壓住 | **零**（結構上不可能）|
| 上限 | 幾乎沒有 | 關節 5–19 度、拉伸 1.11× |
| 工序 | 美術要切、要補畫遮擋、要畫替身 | 丟一張圖進去就好 |
| 適合 | 吉祥物、要演戲的角色 | 生成圖、寫實角色、只要「活著」 |

**如果你要的是 Le Bandit 那種演出 —— 會生氣、會丟帽子、鬍子會掉 ——
那就是切件路線，而且美術工序是實打實的。** 沒有捷徑。

如果你只是要角色「不要死板」，`rig/` 那套一張圖就夠，
但它做不出來這 21 段裡的任何一段。

---

## 7. 如果決定走切件路線，下一步

1. **先確定姿勢**（§2）與**分層清單**（§3）再生圖，不要先生完再想怎麼切。
2. 生圖時**每一層單獨生**，同畫風同角度 —— 不要生一張再去 PS 裡切，
   切出來的遮擋部分要自己補畫，比重生一張貴。
3. 骨架照 §1 的比例擺：地面 → 膝 26%、頭 → 帽頂 24%。
4. **動畫資料可以直接抄**（`le-bandit-motion.md` §3 有 idle 的完整關鍵幀表，
   §7 有 21 段的清單）。骨骼名稱沿用 Le Bandit 的，
   之後要做第二隻角色就跟 Le Prechaun 一樣加次級骨就好
   —— 見 [`le-series-comparison.md`](le-series-comparison.md)。
